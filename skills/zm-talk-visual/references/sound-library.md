# 音效：怎么记录、怎么用

这套做法配过一条 7 分钟的完整口播（174 条音效），全片被认可，音效没有单独评价过。

## 两样东西分开记

| | 记什么 | 放在哪 |
|---|---|---|
| 音效库的记录 | 每个音效本身是什么 | 跟着音效库的文件夹走（`音效库记录.json` 和 `.md`） |
| 片子的音效清单 | 这条片子在第几秒、为什么、用了哪个音效，用户听完怎么说 | 片子的项目文件夹（`音效清单.json`） |

"放在开头还是放在哪里"不记在音效身上。同一个声音这条片子用在开头，下条可能用在结尾。专业音效库（UCS 分类规范、音效厂商的记录指南）也是这么分的：文件的记录只描述声音和来源；用在片子的哪里，记在片子的声音清单上。

音效库在 skill 里：`assets/sfx-library/`。下文说的"音效库文件夹"就是它。来源和许可见那里的 README。

## 音效库的记录：每个音效这些栏

| 栏 | 是什么 | 谁填 |
|---|---|---|
| 分类、材质 | 按声源和材质分，不按用途分 | 起草后用户可改 |
| 描述 | 它本身是什么：东西、动作、特征 | 起草 |
| 还能当什么用 | 搜索用的词：画面上什么时候可以拿它来用；可以有好几个 | 起草，用过之后补 |
| 远近、轻重 | 贴近还是远处；轻、中、重 | 起草 |
| 对齐 | 对在哪（那一帧／动作开始／落点／移动最快处／铺底）和对齐点 | 类型起草，对齐点脚本量 |
| 量出来的 | 时长、听得见的开头、起音、最响处、主体结束、响度、峰值 | 脚本 |
| 压在说话下面 | 能，或只放句间（低音、人声、带旋律、很吵的） | 起草 |
| 来源和许可 | 出自哪个包、原文件、能不能分发 | 已有 |
| 你的评价 | 常用／可用／别用，加一句话 | 只有用户能填 |
| 用过的地方 | 哪条片子、第几秒、什么画面、当时的反应 | 脚本从音效清单汇总 |

前面七栏专业音效库都有类似的（分类、描述、关键词、远近、来源）。"对齐""响度""压在说话下面"是为了让听不到声音的 AI 也能放对位置、放对音量加的。

起草的内容在音效库文件夹的 `记录草稿.json` 里，是没听过声音的情况下按文件名和原有说明写的。用户听了觉得不对，改那个文件，再重跑。

```
python3 scripts/sfx_library.py build <音效库文件夹>
```

## 片子的音效清单：每一行

```json
{"片子": "我的第一条口播 · 开头",
 "音效": [
  {"时间": 6.42, "对着": "百万", "画面": "数字滚到 1,000,000 落定",
   "为什么配": "有分量", "文件": "07_高光与爆点/metal-hit-thud-thump-low-ring-geofon-1.wav",
   "位置": "句间", "音量": -12, "用户的反应": ""}
 ]}
```

- **为什么配**只有四种：讲的东西到了／有分量／换段／玩梗。填不出来就不配。
- **用户的反应**：好、不对（换成了什么）、太响、太轻。听完就填。

把清单汇总回音效库：

```
python3 scripts/sfx_library.py usage <音效库文件夹> <音效清单.json> …
```

汇总之后，每个音效的"用过的地方"能看到它在哪些画面上用过、当时怎么说；有了反应而还没评价的，会自动记一条评价。

## 配一条片子的步骤

1. 画面定了再配。
2. 数出该配的时刻。人声讲内容，音乐给能量和"在动"的感觉，音效只负责"东西到了"和"这一下有分量"。所以：移动的过程不配；装饰不配；一个动作只配一个声音。
3. 选声音：按画面去"还能当什么用"里找；先看用户评价是"常用"的；材质尽量和画面的样子一致（纸卡的画面配纸、卡片的声音）。没有评价的标成"新选的，请听"。
4. 对时间：开始播放的时间 = 画面那一刻 − 对齐点。
5. 定音量：先按"响度"拉平，再分档。和说话重叠的压到人声下面约 20 分贝；重音只放句间，前后把音乐压一点。
6. 用脚本混出来，在成片上量人声和音乐加音效的差；给用户一个能逐条试听的页面。
7. 用户的反应写回清单，跑一次汇总。

## 现在这个库缺的

库里的 `补缺/` 子文件夹补了一批（43 个文件，35 种声音），纸卡落定、笔、键盘、消息提示、点击、清单的小"啵"、短闷击、钱、失败音、快门、处理音都有了。`build` 会把子文件夹自带的 `sounds.json` 一起读进来，记录里每条多了"许可"一栏：补缺里除了"发牌-真实卡片落定"来自 Sonniss，其余 42 个是 CC0；原来的 166 个来自 Sonniss GDC 2026 免费包。

后来又补了 68 个（`补缺/20_短甩` 到 `33_彩纸`：短甩、运镜 whoosh、上升下滑、吸入、上扬铺垫、闪光、落版重击、轻 tick、chime、故障、旋转、电流、落下、彩纸），52 个是 Sonniss 原包里的录音，16 个是 sfx-kit 合成的（CC0），都逐个试听挑过。

还缺的：

- 荧光笔划过。先用"铅笔画线"截一段顶着。
- 一级比一级高的递进音。只有 `tone-step-1` 一级，要递进就在清单里用"变速"把同一个音逐级调高。
- 快进、倒带。文件夹名里写了，里面没有文件。
- 纸卡落定只有两个，同一屏连发四五张会听出重复；小"啵"有五个变体，不存在这个问题。
