## 动作谱
5–8 行，一行一步，按发生顺序：准备 → 主动作 → 收势 → 谁让位 → 镜头怎么走 → 声音在哪。
最后一行写"开始是什么 → 发生了什么 → 结果是什么"。

## 意图
这段演出替观众做了什么、为什么这样拍。

## 动效核心
- 一条一个动作，按发生顺序写（预备 → 主动作 → 余波 → 停住）
