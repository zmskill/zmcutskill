## 动作谱
1. 白底中心一个灰色圆角方块虚着缩成胶囊，"第1天"一个字一个字显影（灰虚 → 墨实），胶囊跟着字变宽
2. 镜头猛往后拉（0.5s，ease-out）：右边标题从左到右显出，上方照片横幅（紫色单色调、虚）出现，整张卡落在画面里
3. 列表一张张往上扫：慢—快—慢，约 1 秒一张；只有正中那张清楚，新卡先是骨架色块再填进内容
4. 整页倾斜（Z −6°、X 透视 18°），照片从下往上退紫露出原色 → 猛甩回页顶（运动模糊）
5. 大标题从虚到实，颜色从紫渐变走到深墨 → 镜头冲向右上角书签按钮、回正
6. 书签停住 → 点下：变实心渐变 + 光环外扩 + 整屏淡紫柔光（全片最亮）→ 渐变流动、白勾写出、柔光呼吸
7. 拉回页面，书签变深色已收藏；声音：tick、whoosh、swish × 2、甩上 whoosh、推近 whoosh、点击 bloom、打勾 chime、反向 whoosh
8. 开始是一颗空胶囊 → 生成的行程一张张出现、被收藏 → 结果是页顶上一个已收藏的书签

## 意图
用"一个镜头不断"把"生成结果 → 浏览 → 收藏"演成一件连贯的事：观众先看到细节（胶囊），再看到全貌（列表），最后看到用户的动作（收藏）。
照片从紫色单色调变原色，是"结果从草稿变成真东西"的暗示。

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 开场缩放 | 9.0× → 1.8×（1.1–1.6s） | 命门：拉出必须在 0.5s 内，太慢就成了平移 |
| 扫一张卡 | 快扫 0.35s + 慢看 0.65s | 命门 |
| 倾斜 | Z −6°、X 18° | 再大字会糊 |
| 甩上去 | 0.35s，纵向运动模糊 | 命门 |
| 冲书签 | 5.75–6.3s，缩放到 4.6× | 命门 |
| 点下柔光 | 7.03–7.17s 最亮 | 命门：亮太久像闪白 |
| 模糊 | 一律按屏幕像素写，再除以镜头缩放 | 不这样做，9× 特写时 5px 会变成 45px（已踩坑） |

## 已知坑
- 页面里的 blur 会被镜头缩放放大：写成屏幕像素 / 当前缩放（`bl(c, px)`）
- 镜头推到 4–5 倍的特写里，小元素别留在页面里被 CSS 放大：每帧重新采样会抖（用户 2026-11-10："我们这个有点抖，他们的好像没有那么抖"）。书签特写段改成画在屏幕上、按真实大小直接画，柔光呼吸从 ±30% 降到 ±6%，抖动最大值 2.9 → 0.95 像素
- 柔光和光环用径向渐变画，不用大半径 box-shadow 或 border + blur 滤镜：Chrome 渲大面积模糊会分块，2 倍渲染时 7.2–7.4s 能看到方格（2026-11-10 补做逐帧检查时发现，v3 已改）
- 点下的整屏柔光会把书签本身盖淡：柔光中心留出按钮半径的透明区
- 原片是真照片（里斯本街景），版权和代码都不能用：换成扁平插画，质感比原片弱
- 结尾比原片多 0.7s（原片 8.9s 直接切走），为了让镜头组停在一个完整结果上
