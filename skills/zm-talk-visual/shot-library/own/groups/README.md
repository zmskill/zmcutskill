# 镜头组

**镜头组** = 几个镜头连起来，演完一段完整意思（例："问题 → 产品登场 → 结果"），一般 4–25 秒。
**镜头卡**（`../cards/`）是零件，镜头组是用零件拼成的一段完整演出。做片时 AI **先按镜头组选，镜头组覆盖不到的地方再用镜头卡补**。


| | 镜头卡 `cards/` | 镜头组 `groups/` |
|---|---|---|
| 是什么 | 一个画面、一个手法 | 一段完整讲法，含进场、转折、收势 |
| 长度 | 1–4 秒 | 4–25 秒 |
| 来源 | 拆片时剪成"单个镜头"的段 | 拆片时剪成"一拍 / 一串"的段 |
| 代码 | `demos-own/<类>/<卡名>/` | `demos-own/groups/<组名>/` |
| 合同 | 可选（建议填输入和字数上限） | **必填**（见 `TEMPLATE.md`） |

## 规矩

1. **有合同才算镜头组**：卡上必须写清讲法、阶段、数量、时间（动作区 / 停留区 / 落点）、输入和字数上限、素材、进出、音效清单。
   代码里有一份同样内容的 `<NAME>_CONTRACT` 常量，**卡上的数字从代码常量抄，不各写各的**。
2. **AI 用镜头组只能填输入字段**：截图、文案、品牌色、声明过的布局（横 / 竖）。不改缓动、不改动作区速度、不凑数量、不超字数。
   装不下就换组或报告，不硬塞（见 `aesthetic-rules.md` P6）。
3. **成熟度**：每个镜头组标一级。
   - **候选**：复刻检查 + 上限文案验证通过，用户在对照页选了"要"。
   - **已用**：做进过一条真实成片，用户看过说好。
   - **稳定**：至少两条不同内容的片子用过，用户都认可。
   做片时优先"稳定"，其次"已用"，最后"候选"；用"候选"时在设计 spec 里写明风险。
4. **成熟度只在复盘时升级**，升级要有用户原话，写进卡上的"用户裁决"。
5. 时间写**秒**，另标帧率；帧号只在代码里换算。时间换算用 `shot-library/kit/groupClock.ts`。
6. 改了组或加了组，在 `index/library-own.json` 里加一条（镜头组的 `kind` 是 `group`），并在 `index/koubo-fit.md` 里登记。
