## 动作谱
1. 准备：黑底，一个巨大的深蓝渐变框（一角发蓝光）里是乱码；框的四条边延长成贯穿全屏的引导线，交点有白方点
2. 主动作 1（0–2.9s）：相机后拉 → 一帧跳机位、第二个框出现 → 快速环绕（两框视差、前后层级翻过来）→ 上仰落定，两个词都解码完；安静慢滑时已定的字又闪一下；最后绕竖轴加速甩
3. 主动作 2（2.9–7.0s）：硬切成 3D 标签环：侧立的窄环顺时针狂转，同时倒下、拉远，标签一帧冒几个（2→20）；平躺慢转 → 俯冲 → 一帧翻转 → 近景沿蓝色光带慢漂 → 推近甩出
4. 让位（7.03s）：一帧换成射线图，中心方块位置连续（整串的锚点）；射线上的彩色小方块带着编码往中心流
5. 主动作 3（7.2–10.37s）：白底面板从右硬推进来，撞上中心方块、推着它往左；面板上一排等高短划先静着，再远端先涨高，波形每帧往右流一格，越远越稀；面板先减速到几乎停、再加速铺满屏
6. 收：白底蓝柱 / 黑底白柱 1–3 帧交替频闪，相机猛推进柱子，剩一根柱子
7. 声音：解码 tick 串、环绕 whoosh、字定住 blip、甩 whoosh、旋转 swirl + 标签 pop、翻转 whoosh、换场 thump、面板撞上 tick、录音声淡入、频闪 glitch + riser
8. 开始是两个乱码里解出来的词 → 变成一圈很多词、汇到一个点 → 结果是一段在流动的录音波形，冲出画面

## 意图
把"很多零散记录被收拢成一段可用的东西"演出来：词 → 词的网络 → 一个点 → 一条声波。中心方块从环到射线到面板一直在，是观众的视线锚点。

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 乱码 | 每个字的码位 ±1 游走（相邻汉字），平均约 2–3 帧变一次，首字最后定，定前对了又跑一格 | 命门：不是从左到右逐个定住 |
| 环狂转 | 开头 45°/帧，5 帧转半圈，同时倒下、拉远 | 命门 |
| 标签冒出 | 2 个 → 20 个，3.1–3.47s 一帧冒 1–3 个，20 个槽位均匀 | 槽位不均会扎堆（已踩坑） |
| 中心方块 | 环段恒定 82px（不随推拉缩放） | 命门：它是锚 |
| 换场 | 7.033s 一帧，只留一个方块 | 两个方块同时出现很乱（已踩坑） |
| 面板推入 | −110px/帧 → 减速 → 撞上方块 → 先减速到 2px/帧再加速到 −68px/帧 | 命门 |
| 声波 | 柱宽 8.5px、近端间距 22px，越远越稀；高度图案每帧右移一格；近方块处永远小 | |
| 频闪 | 12 帧：白黑黑黑白白白黑白黑黑白 | 命门：不是反色，是两套配色 |

## 已知坑
- 中文乱码：码位 ±1 的相邻汉字常常是生僻字（"仇旨徉加""陪手灵感"），看起来像真字被打错，比原片英文乱码更"像字"；如果想更乱，要换成别的取字办法
- 环上标签起初按黄金角放，冒出来时扎在一起；改成 20 个均匀槽位、打散顺序填
- 俯冲 + 翻转（4.2–4.9s）比原片弱：原片那一帧翻转活动值 29，我们 14（我们的环翻过来后标签比原片少、比原片小）
- 推近甩出（6.6–7.0s）也比原片弱：原片 23，我们 16
- 声波形状：原片是"整片涨起来、越往右越高"的包络，我们是一团一团的（中间有几处变很小），更像说话，不像原片那样连成一片
- 字体：云端渲染是 Noto Sans CJK，不是苹方
