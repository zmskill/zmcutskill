## 意图
开场 5 秒抛一个让人点头的问题，再用"满屏都是消息、还在一直流"把压迫感具体化；最后过曝变白，干净地交给下一镜（通常是产品登场）。

## 动效核心
- 问句（0–40f）：两行逐词浮现（模糊 12px→0、上浮 16px），关键词红色带柔光
- 飞入（48–84f）：通知卡从右前方（+1500px 横、+1100px 近）沿弧线飞到飘带上，右边的先到，飞行中按速度模糊；飞过问句时问句虚 9px、淡 45%，然后在上方清楚回来
- 流动（60f 起）：飘带持续往左流（每帧 ~9→13px），卡片沿弯曲的飘带走，到两边自然变远、变虚；118f 起加速
- 出场（110–150f）：飘带中间先亮起一个有体积的小光球，然后整屏失焦 0→16px + 过曝，146f 起纯色，接下一镜

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 飘带 | 4 行 × 44 列，卡 118×86，z = -0.00042·x² | 弯曲系数越大两边越快远去；太小就成了平板 |
| 流动速度 | flow = -(9g + 0.04g² + 0.45g2²)，g = f-60，g2 = f-118 | 原片实测每帧 ~12px（1080p），结尾 ~28px；匀速会显得机械 |
| 飞入 | 每张 26f，EASE.out，右边先到（错开 18f） | 飞得太快看不清"从镜头前掠过"，太慢拖节奏 |
| 问句虚化 | 58–82f，峰值 9px | 要和卡片飞过问句的时间对上，早了就像问句自己在虚 |
| 出场 | 光点 110f 起、失焦过曝 118–146f（对称缓入缓出） | 用户要的是"丝滑"，不要突然一团白光 |

## 怎么换内容
- `LINE1 / LINE2`：问句，关键词标 `hot: true`
- `APPS`：通知卡的 App 名、颜色、标题、一句内容（换成目标用户真实会收到的消息）
- 暗场配色在根节点背景和地平线光里改；亮场版本参考 shot-lab/_待定/question-card-ribbon（未入库的试验版）

## 声音
- 问句：无或一声轻的 riser 起头
- 卡片飞过：一道 whoosh，钉在 56f 左右（飞过问句那一刻）
- 出场过曝：上扬的 riser 收进下一镜的第一拍

## 已知坑
- 卡片很多（176 张），飞行段每张都有模糊，渲染比普通镜头慢
- 问句要在飘带上方（marginTop 收到 170），否则会被飘带挡住
- 用户对前几版的意见（已改进本版）："过渡不够丝滑自然""原片从左到右的丝滑过渡呢"（→ 飘带要一直流，不能原地起伏）
