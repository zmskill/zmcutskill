## 意图
把"点一下"这个看不见的动作放大成一个事件：按钮先缩（按下去了）→ 颜色变（生效了）→ 光往外推（被系统接住了）→ 写出勾（完成了）。因果顺序清楚，观众不用读字也知道"存好了"。

## 动效核心
- 书签特写居中停住，镜头极慢推近（≈1%/秒）
- 6.95s 按钮缩到 0.95（2 帧）
- 7.03s 书签从描边换成实心渐变（1–2 帧），按钮外起一圈柔光
- 7.03–7.35s 三圈软光环错开 0.035s 往外扩；7.07–7.2s 整屏淡紫 / 淡蓝径向柔光，7.10s 最亮，中心留出按钮那一圈不盖
- 7.12–7.22s 按钮放大到 1.28，再落回 1.2
- 7.45–7.67s 白勾写出（先短边后长边）
- 之后渐变慢慢流动、柔光 ±6% 呼吸，按钮缓缓缩回 1.1

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 按下 | 0.95，0.07s | 再深像卡住 |
| 最亮 | 7.07–7.2s | 命门：亮太久像闪白 |
| 放大 | 1.28 → 1.2 | 超过 1.35 显得夸张 |
| 写勾 | 0.22s | 太快看不出是写出来的 |
| 柔光呼吸 | ±6%，约 2.9s 一周 | 命门：±30% 时用户说抖 |

## 声音
点下：短促 click + 柔和 bloom（落在 7.03s）；写勾：清脆 tick 或小 chime（7.45s）。和镜头组合同里的 tap、check 两条一致。

## 已知坑
- **特写主角要按屏幕大小直接画**：在页面里画 80px 再被镜头放大 4–5 倍，每帧重新采样会抖（v1 用户指出）
- **柔光和光环用径向渐变画，不用大半径 box-shadow / border + blur 滤镜**：Chrome 渲大面积模糊会分块，2 倍渲染时能看到方格（2026-11-10 逐帧检查发现）
- 整屏柔光中心要留出按钮半径，否则书签在最亮那几帧被盖淡
