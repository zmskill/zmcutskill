## 意图
一口气把很多功能 / 场景过一遍，但不像幻灯片一张张切：观众像站在一个圆筒里，卡片从身边流过去，中间那张看清楚，两边的被拉弯、拖虚，速度感和空间感都有了。

## 动效核心
- 外框：每张卡切成 40px 竖条，竖条贴在半径 R 的圆筒上（相机在圆心，R = 透视距离），投影后中间 1:1、两边自然变高
- 额外拉高：屏幕中间 45% 宽是平的，往外按 e² 再拉高最多 60%（每条用投影矩阵变成梯形，边缘连续不出台阶）
- 边缘：横向单向模糊（SVG feGaussianBlur "x 0"，7 档）+ 上青下紫顶黄的竖向色散（drop-shadow，只变透明度不变位移）
- 地面：每张卡下面一团同色软影，跟着卡的投影位置和放大量走
- 速度：匀速（~7.7px/f）+ 3 次甩动（f 380/620/880，高斯峰 +30px/f，σ=9f），甩动时整体更虚；1222–1290 减速，最后一张停在正中，停 3 秒
- 卡里：每张卡的本地帧 lt 从"卡心到正中右边 450px"起算，小场景在卡经过正中的 3–4 秒里演完高潮

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 透视 / 圆筒半径 P | 1150（备选 900） | 越小弯得越深、两边越早虚；640 时中间的卡也虚了，太狠 |
| 平坦区 | 屏幕中间 45% | 再小中间的字就看不清 |
| 额外拉高 | 最多 +60% | 原片边缘接近 2 倍 |
| 色散 chroma | 0.6（备选 1） | 色散位移固定、只变透明度，否则条与条之间出台阶 |
| 竖条宽 | 40px，每条多盖 2.5px | 太宽边缘有台阶；不多盖会有细缝 |
| 底速 | 自动解出，让最后一张卡在 1290f 正好停在正中 | 原片 ~6px/f（180px/s） |

## 怎么换内容
- `CARDS`：每张卡的宽、底色、地面影子颜色、小场景组件；增删卡后速度会自动重算
- 小场景组件（`SceneNeeds`、`SceneSearch`……）都是纯函数 `({lt, w})`，改文案就行
- **文案按手法配中性内容，只有 Logo / 收尾卡放产品品牌**（见已知坑）
- 配色：`CFG[2]`；`CFG[1]` 是更弯更炫的备选

## 声音
- 全程一条有律动的音乐；3 次甩动各配一道 whoosh，钉在 380 / 620 / 880f
- 最后减速落定：落地重击或闪光，钉在 1290f

## 已知坑
- 模糊必须放在竖条里面的内容上，不能放在竖条本身，否则条边透出竖线
- drop-shadow 不能带模糊半径（会横向漫到隔壁条，出现竖向亮线）
- 每张卡在正中只停 3–4 秒：小场景要早点开演，"输入框打字"一开始演太晚，结果在卡滑过中间后才出来
- 用户意见（2026-11-05）：这版 15 张卡的文案全在讲"逐梦的剪辑 skills"，用户觉得"都是宣传我的 skills 就会很奇怪""内容有点偏向"。
  以后用这个镜头：先想每个手法适合放什么内容，配中性的内容，只有 Logo / 收尾位放产品
- 原片卡里是别人整段的产品片，内容很丰富；我们是画出来的小场景，对照起来朴素一些
- 渲染约 1.5 分钟（1380 帧）
