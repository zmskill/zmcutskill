## 动效核心
- 几十张卡贴在偏左的椭圆筒上螺旋上升；数字和卡在同一个 3D 场景里，前后互相遮挡
- 数字 `floor(终值·i/N)` 每帧都变，等宽、居中，两端橙中间黑的横向渐变；下面一行逐词浅灰带虚 → 变黑
- 甩镜头：匀速 → 三次加速 → 峰值 → 双指数长尾，不停死；数字在峰值那一帧落到终值
- 离场：所有卡变虚往中心收，切进毛玻璃"相册"文件夹，两张卡往里沉

## 怎么换内容
- 终值和下面那行字；场景卡在 sceneCards.tsx（16 种：城市夜景、咖啡、海边、猫、书桌、跑步……，和 card-tunnel-tagline 共用）
