## 意图
观众的眼睛一直停在画面中下部的同一块卡框上：按钮 → 新建卡 → 列表 → 被拖、被改、被勾，卡框位置从头到尾几乎不变，只换卡里的内容。
上方大字负责"说"，下方界面负责"做"，两者差半拍，叠着走不留空。

## 动效核心
1. 开头 0.2s 真静止（只有蓝胶囊 + 右下光标），然后大字逐字从下浮上来、由灰变黑、去虚，两行重叠打，左边缘固定
2. 光标从右下飞向按钮（快段 5 个拖影），按下 0.93× → 回弹 → 卡片从按钮身后撑开：上沿基本不动，往左右和下方长，前 0.12s 到 90%、长尾巴补完，前几帧整体虚；按钮压在卡上淡出；水波圈扩开
3. 输入框普通打字（不浮），竖线闪两下熄灭；三个标签每 0.17s 一个从 0.5× 长到 1.0（无过冲）——曲线低但每 0.1s 都有东西在长
4. 点"加入列表"：按下 0.92× → 水波圈 → 卡吸一口气（略缩、下沿先冲到 86% 再收回）→ 旧内容和列表交叉溶解 → 三行从下往上依次浮入，新行再从右往左滑一点 → 计数 2→3 与青柠绿描边同一帧
5. 换场 = 前景（字 + 卡）一起放大 1.08× + 横向运动模糊 + 淡出，最空 1 帧，三词带糊从下往上落位；列表回到完全相同的位置；背景不糊
6. 排：拿起 2 帧（放大 1.03 + 投影）→ 停 0.3s → 0.5s 拖到顶（中段最快，被拖行在最上层，被越过的行依次让开）→ 放下；光标钉在"取"字上一起走
7. 改：词先滚 0.17s（位置 / 大小 0.73↔1 / 颜色同步、竖向轻糊），侧卡晚半拍从右边带横糊滑入（长尾 ease-out，无回弹）→ 时间字段聚焦 → 点 + 水波 → 旧值上浮淡出、新值灰→黑 → "已保存" + 列表那一行的时间同步变 11:30
8. 勾：侧卡 ease-in 加速滑出，还剩 1/3 时词就开始滚；"勾一下"从淡紫变品牌蓝 + 微光；按下 → 实心蓝 + 水波圈 + 彩纸从左上喷出 → 白勾描出 → 删除线左往右划 → "已完成"胶囊弹出、计数 3→2；光标顺手悬停下一行（勾选圈泛青柠）再滑出画；彩纸上冲 0.3s、悬停、翻转飘落、淡出
9. 出场和第 5 步同一个甩糊，最后 2 帧只剩背景（下一镜可以在同一位置弹出新按钮）

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 卡框位置 | x 410–1510、上沿 518 | 四拍都不许动；动了就失去"同一张卡"的意义 |
| 撑开 | 0.43s，前 0.12s 到 90%，初始虚 8px | 超过 0.5s 会软；不要从中心等比放大 |
| 甩糊 | 放大 1.08×、横糊 20px、去 0.25s / 回 0.3s | 放大 >1.12 像镜头冲撞；去掉横糊就成了普通淡入淡出 |
| 三词 | 当前 116px，上下 0.73×，行距 112/132px | 只显示当前 ±1；"勾一下"当前态再大 1.06× + 蓝光，补中文等宽的冲击力 |
| 滚词 | 0.17s ease-in-out | 慢于 0.25s 会和界面动作挤在一起 |
| 侧卡 | 入 0.52s ease-out、出 0.36s ease-in，行程按画宽拉长 1.51× | 收回比弹出快是关键 |
| 彩纸 | 42 片，蓝 / 淡紫 / 青柠 = 2:1:1，射程 150–400px | 只在左半边，别盖住大字 |
| 打字 | 输入框 9 字/秒；大字 15 字/秒、每字 0.1s 浮起 | 大字和输入字两种打法要分开 |

## 已知坑
- 卡框只能有一个容器：新建卡和列表是同一个 div 的两套内容交叉溶解，做成两张卡一出一进会断
- 甩糊只作用在前景，背景不糊；甩完列表必须回到原像素位置（jitter_check 拖动段只在放下那 2 帧有 ≤5px 回收，是 1.03→1 缩放本身）
- 原片穿帮已修：改时间后列表那一行同步变 11:30；完成后计数 3→2
- 1080p 下原片的小字（18px/1200）太小，界面字号整体放大到任务名 28px、标签 18–20px
- 渲染环境：用户电脑的 Linux 虚拟机里 rspack 原生模块一加载就 Bus error、也下载不到 headless Chrome，本条在云端容器（x86 + Chrome for Testing 153 + Noto Sans CJK）用 `--scale=2` 渲染再 lanczos 缩回 1920（= `--hq` 同样流程），渲染出的字体是 Noto Sans CJK SC；在 Mac 上用 render_shot.py 渲染会换成苹方，字宽略有差别
