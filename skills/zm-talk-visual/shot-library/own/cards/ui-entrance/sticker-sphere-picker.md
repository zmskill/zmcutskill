## 意图
把"在几百个东西里一下找到要的那几个"变成一个看得见的动作：球是全部、变暗是筛掉、转到中间是找到。

## 动效核心
- 图标淡掉 1 帧后，半透明玻璃球从按钮左上冒出，边转边长大、沿弧线飞到上方
- 三次拖转（横转 / 反转 / 斜翻露出极点、停住后歪约 10°），都是快起慢收
- 弯曲的搜索胶囊沿球外圈，打字时沿弧变长；不匹配的变暗到约 12% 留在原位
- ↓/↑：计数先变、球后转，蓝框贴在球面上、只在停稳时出现
- 点击：按下 → 弹到 1.45 倍 → 回位，连点 3 下瞬间插入输入框
- Esc 两次：先清空搜索全亮回来，再胶囊失焦糊掉、球缩回按钮；最后 ⌘A + ⌫，首尾接上

## 怎么换内容

## 已知坑
- 规整网格快转会出现车轮效应（看起来倒着转）：快转那几帧加了很淡的拖影，原片没有；介意就把转速调慢
- 彩色方块图标比原片的圆形 emoji 显得更密更亮
- 界面字按原片比例，偏小
