## 意图
"从一大群人里挑出对的人、再整理成名单"——同一批卡片一路变形（铺开 → 选中 → 展开 → 收成小条 → 变成表格行），不靠硬切讲完整件事。

## 动效核心
- 上排往左、下排往右交错滑入，中间一排原地替换搜索框；第二次 3 帧猛后拉 + 网格逆时针 3.5°、四周景深
- 选中三态：悬停浅蓝 → 按下深蓝内容变淡 → 松开浅蓝 + 角点选框；陈默选了又退选
- 没选中的退成背景虚影（外圈、底排先退），选中的三张摆正散开，字段每帧一行往下长，"很合适"错开 0.2s 弹出
- 收拢：字段从下往上收 → 小条竖叠漂一下 → 一条条落进表格变浅蓝骨架（斜边擦出）→ 扫光填字 → 绿勾
- 名单先下移让位，三词标题逐词浮现；后拉最快一帧硬切；金句逐词；新搜索框冲上来轻微过冲；冲近发送键按下出玻璃高光；泛蓝转场

## 怎么换内容
- 人物卡数据、搜索句、详情字段、名单表头、三词标题、金句、第二句

## 已知坑
- 原片背景是实拍植物白墙，这里是虚的渐变光影；新搜索框冲上来时白框配白墙不如原片醒目
- 网格倾斜只做了 2D 旋转（没加透视），景深按卡片分档
- 详情字段和表格小字约 17–24px
