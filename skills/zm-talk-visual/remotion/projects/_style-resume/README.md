# _style-resume：简历风格（讲本事是怎么攒出来的）的模板

风格卡：`styles/resume/STYLE.md`（先读《招牌动作》《锁死的和要拧的》）。

> **只照示例往表里填格子，会是这套的调调。** 每条片子最重的两三句，要在这张表上现做一个新的场（连线、翻背面、装信封、价签划掉……），见风格卡《换内容的地方》第 4 条。

## 文件

| 文件 | 是什么 | 换片子改不改 |
|---|---|---|
| `setup.ts` | 口播视频路径 `VIDEO`、画面上用到但字幕里没有的字 `EXTRA` | 改 |
| `subs.json`、`subs_chars.json` | `scripts/align_script.py` 出的字幕和逐字时间 | 换成自己的 |
| `Kit.tsx` | 外壳 `Shell`（纸 → 表 → 人 → 浮层 → 字幕）、人的三种状态、章、手写、勾选框、截图附件、回形针、表格线…… | 不改 |
| `Base.tsx` | 表头 `FormFrame` / `HeadFill`、下半张 `Page`（一页页翻）、多栏表 `RowTable`、技能章 `SkillTag`、连线 `Connect`、弹出卡、对比条、想法云、便签、附件 `Att` / 录屏附件 `VidAtt`、线描小人 | 不改；缺零件就加在这里 |
| `Example.tsx` | 23 秒示例（虚构内容，人用灰色人形占位），不需要素材就能渲染 | 照它的写法写自己的段落 |

## 换一条片子

1. 口播初剪转 30 帧/秒放进 `remotion/public/<片子名>/src.mp4`，截图放同一个文件夹；`setup.ts` 的 `VIDEO` 写 `'<片子名>/src.mp4'`。
2. 字幕：`subs.json`、`subs_chars.json` 换成这条的。`EXTRA` 填表头、表格、章、便签上要写、字幕里没有的字。
3. 分段：每段一个文件（照 `Example.tsx`），导出组件和帧数。段的边界落在两句话之间，各段帧数加起来等于全片；每段 `Shell` 的 `t0` 是这段起点秒数（= 起点帧 / 30）。
4. 时间一律用 `W('字幕里的几个字', 不早于第几秒)`：说到哪个字，东西就在那一刻出现。
5. 在 `remotion/src/Root.tsx` 登记：`K('id', 组件, 帧数, 1080, 1920)`。

## 人的三种状态

`Shell` 的 `keys`：`[[秒, 'full' | 'photo' | 'corner'], …]`。满屏 = 对观众说话、提问、讲心里话；照片格 = 讲经历、填表；附件角 = 截图放大看的时候缩到右上角（白边加回形针）。切换 20 帧。人满屏时下层的表不画，可以趁这几秒换掉下半张。

## 写的时候要注意

- 字体和书桌风格共用（霞鹜文楷、Fraunces）：渲染前 `styles/desk/fonts/` 要在 `remotion/public/fonts/desk/`，`scripts/workdir.sh` 会自动复制；没复制的话手写字会退成黑体。
- `Page` 有 `zIndex`，会盖住后面没写 zIndex 的东西：要压在下半张上面的（连线、大章），包一层 `zIndex: 20` 的 div（见 `Example.tsx`）。
- `W()` 要求那行字幕的开始时间 ≥ "不早于"的秒数：段的第一句正好压在段起点上时，往前放一点（`W('那最后', 段起点 - 0.5)`）。
- 下半张只有 960 × 740，弹出卡和表格要算好大小，超出会被裁掉。
- 表格里的字偏小（30–44 像素）：重要的信息用弹出卡、章或便签放大说，不要只靠格子。
- 录屏放进附件用 `VidAtt`（里面用 `Freeze` 定帧，`startFrom` 逐帧算会错位）。
- 表里只写口播里说过的词；口播没说的格子留灰条。
