# 书桌（日常分享，拿截图说话）

- **给用户**：你的手机就放在书桌上，聊天记录、后台数据一张张摆上来，说到哪条，就把哪条拿起来给观众看。
- **给 AI**：整条片子发生在一张固定的书桌上（暖色纸面，百叶窗和树叶的影子）。人在桌上的一部手机里当配角；证据是桌上的手机和冲印出来的截图，一张张"换上来"放在正中，说到哪几条消息，就把那几条原样拿起来放大（证据跳出来），底下退暗；关键词像排版一样印在桌上（粗宋体），小批注写在便签上（文楷）。文案是日常分享、讲自己做成的一件事，手上有聊天记录、后台数据、评论截图这类手机截图时用。人想一直满屏、靠表情撑的不用；横屏、素材多是照片和笔记的用笔记本；演示软件怎么用的用操作台。
- **ID**：`desk`（文件夹名，定了不改）。取名规则见 `references/style.md`《风格卡取名》。
- **画幅**：竖屏 1080×1920。

## 和相近的几套怎么二选一

| 想选 | 看什么 |
|---|---|
| 书桌 vs 笔记本 | 证据主要是**手机截图**（聊天、后台、评论）、竖屏、想要"日常分享"的松弛感 → 书桌；横屏、证据是照片/笔记/数字、讲经历和成绩 → 笔记本 |
| 书桌 vs 操作台 | 讲**自己做成的一件事**、证据是截图 → 书桌；一步步演示软件怎么用、手上有录屏 → 操作台 |

## 一句话意象

一张洒着午后阳光的书桌：你的手机放在桌上，聊天记录、后台数据一张张摆上来，说到哪条，就拿起哪条。

## 好在哪（做新片子先读这一节）

这套样子来自一条讲副业的竖屏日常分享（127 秒，作者带粉丝卖邀请码），前三版都被作者否了，第四版才对味。真正起作用的是下面几件事，按片子里出现的顺序：

| 场 | 哪句话 | 证据 / 画面 | 怎么摆、怎么动 | 配什么声 |
|---|---|---|---|---|
| 开头 0–3 秒 | "我的粉丝看我视频去卖……" | 人在手机里，手机几乎占满屏，桌边露出来 | 开头离人近（建立信任），说到第一个关键词时手机缩到左边，右边印上"几百" | 印字一声小"啵" |
| 证据 4–8 秒 | "他是我发视频的第一天就跟着做的 / 当天晚上就来跟我报喜" | 三张粉丝聊天截图 | 每张从右边滑进来、放正中、占满宽度；**说到哪几条，就把那几条消息原样从截图上拿起来、放大到眼前，底下截图退暗**，再用红笔圈一下 | 换截图：纸张声 / 手机轻划；消息跳出来："收到消息"提示音；圈：铅笔划纸 |
| 证据合集 8–10 秒 | "这是聊天记录啊，绝对真实" | 四张聊天截图 | 一张张落在桌上排成扇形 + 粗宋体"聊天记录"、红字"绝对真实"。**不拉全景、不飞镜头** | 四声纸卡落桌 |
| 价格战 31–36 秒 | "好多人已经卖到九块九了" | 真实价格：25、19.9、9.9、15（都来自口播和截图） | 做成纸价签一张张往下掉，前一张被红笔划掉；数字用 Fraunces 斜体 | 价签落下 + 划掉 |
| 对比 46–68 秒 | "最早来买的人… / 那现在呢…" | 没有截图，只有口播里的词 | "以前 / 现在"两张横线索引卡上下叠：说到谁，谁的卡亮，另一张退暗但留着；标签按说到的顺序一个个贴上 | 每个标签一声小"啵"（几个变体轮换） |
| 话术 76–93 秒 | "话术要满足三点 / 我把话术都整理好了" | 作者自己的客服原话 | 三点写在一张纸上，每点下面是原话，讲完打勾；整理卡分 3 页、完全静止，方便观众截图 | 打勾声；翻页纸张声 |
| 收尾 121–127 秒 | "成功之前要失败十次，前面九次一次都省不了" | — | 十个格子，前九个依次划掉，最后一个亮起"成功" | 最后一格一声小铃 |

共通的道理：
1. **一次只看一样**：每个画面一个主体；证据跳出来时其余退暗。依据：Mayer 提示原则、Abrams & Christ 的"刚出现的东西才抓眼睛"。
2. **镜头不飞，东西被换上来**：桌面固定，换场是"旧的往左滑走、新的从右滑进"，方向全片一致；落定后停够让人读。推拉 + 平移 + 旋转同时做、全景↔特写大幅缩放会晕（第二版就是这样被否的："晕头转向"）。
3. **素材自己活过来**：证据不是贴上去的图，是把截图上那几条消息原样拿起来——只有真素材做得出来，内容、素材和人加在一起才会一加一大于二。
4. **人是配角**：人在桌上的手机里，只在建立信任、对观众说话、情绪在脸上时出来，其余时间让位给证据。
5. **真实的东西做成桌上的物件**：价签、便签、索引卡、冲印照片——都是桌上会有的东西，不画抽象图形。

## 适合 / 不适合

- 适合：日常分享、讲自己做成的一件事（副业、项目、粉丝案例）；竖屏；手上有聊天记录、后台数据、评论区这类**手机截图**。
- 不适合：没什么截图、全靠人说的观点类；软件操作演示（用操作台）；横屏（没试过，桌面布局要重排）。
- 需要的素材：5 张以上真截图。截图越清晰越好：电脑上截的小图（四五百像素宽）放大后会糊，尽量要手机原图。敏感信息（别人的头像、昵称）先打码。

## 值

- 颜色、字体：`remotion/projects/_style-desk/Kit.tsx` 的 `D`（桌面 `#efe5d6`、墨色 `#2b211b`、红笔 `#d9502e`、荧光黄、纸白）；给镜头库读的那份在本文件夹 `values.ts`（`DESK`）。用户想换配色改 `D`。
- 字体（都是免费商用 OFL，见 `fonts/README.md`）：标题 Noto Serif CJK SC Black（粗宋体，系统字体）；批注、便签这类手写字用 LXGW 文楷粗体；数字 Fraunces 斜体；字幕 Noto Sans CJK SC Bold，奶白圆角底。`@font-face` 在模板的 `fonts.ts`。圆滚滚的卡通手写体试过、显廉价，不要用。
- 动效：换上来 15 帧 snappy、拿走 12 帧 swift；证据跳出来 16 帧 overshoot，放大 1.7–2.6 倍，底下退暗 62%；红笔圈 12–14 帧画完；价签掉落 13 帧 overshoot。
- 光影：百叶窗影子（模糊 28px、正片叠底、慢慢晃）+ 四周暖色暗角；桌上东西的影子光从左上来（`deskShadow`）。

## 代码

- **模板**：`remotion/projects/_style-desk/`。换片子大部分只改 `content.ts`（加上 `subs.json`、`subs_chars.json` 和 public 里的素材）；高点在自己项目那份 `Scenes.tsx` 里现做。说明见那里的 `README.md`。`Kit.tsx` 是零件（桌面、字幕、手机、冲印照片、红笔圈、证据跳出来、人在手机里、价签、索引卡……），`Scenes.tsx` 是每种场怎么画（shot / fan / tag / card / checklist / pages / loop / stairs / grid / quote / rec 等 20 种），`Film.tsx` 把每一段登记成 `desk1`、`desk2`…（竖屏 1080×1920）。
- 现在 `content.ts` 里是一条 24 秒的假示例（不用任何素材就能渲染，`desk1`、`desk2`），样子见 `样片/换了内容的示例.jpg`。
- 模板是从原片代码拆出来的，验收是只填 `content.ts` 把原片重做一遍，抽 84 帧和原片逐像素比，看不出差别。
- 字体：`styles/desk/fonts/`，渲染前要在 `remotion/public/fonts/desk/`：`scripts/workdir.sh`、`setup.py remotion` 会自动复制。

## 招牌动作

1. 证据跳出来：截图上说到的那几条原样拿起来放大，底下退暗，再红笔圈。
2. 东西被换上来：桌面不动，旧的往左滑走、新的从右滑进正中。
3. 一组截图落在桌上排成扇形（"这么多都是真的"）。
4. 数字变化做成纸价签往下掉、前一张被划掉。
5. 对比做成上下两张索引卡，说到谁谁亮。
6. 人在桌上的手机里，开头大、后面当配角，高点可以拉到几乎满屏。

## 锁死的和要拧的

只往模板里填内容能出片，但一整条看下来会"太重复了，都是一个调调"（用同一套模板只填内容做的测试片，作者就是这么说的）。通用的道理见 `references/picture-and-words.md`《主题不变，变奏不停》；这套具体是：

- **锁死**：暖色桌面和百叶窗影子、`D` 的配色、粗宋体 + 文楷 + Fraunces、换场方向（旧的往左走、新的从右来）、镜头不飞不转不整屏模糊、一次只跳出一样。
- **要拧的**（这套里能拧成什么样）：
  - 主体：手机截图 / 冲印照片 / 录屏 / 价签 / 索引卡 / 便签 / 印在桌上的大字 / 人
  - 大小：整张占满宽度 / 只拿起几条放大 / 一组扇形落桌 / 一墙 / 人几乎满屏
  - 来法：滑进 / 落桌 / 跳出来 / 往下掉 / 手写出来 / 砸下来 / 被划掉换成别的
  - 节奏：一串截图快速落桌 / 一张停住慢慢推近 / 整理卡完全静止
  - 人：手机里大（开头）/ 小 / 滑出去 / 回来；高点可以让手机拉近到几乎满屏（位置 `F`）
  - 声：纸张、提示音、铅笔、价签落、小铃、停一下
- 模板里 `shot` 最省事，最容易一路 shot 到底。连着两拍都是 shot，第二拍至少换大小或来法（这一张只拿起一条、不放整张；或者几张一起落桌）。
- **每条片子的两三个高点现做**：从这条的素材里找只有它有的东西，做成一个新物件或新动作（比如：后台数字一位一位翻上来；评论一条条从手机里涌出来堆满桌；截图越落越快堆成一座山；一张小票把几个环节一行行打出来）。在自己项目那份 `Scenes.tsx` 里加新的 type，不改 skill 里的模板。用户说好的，问他要不要加进模板。
- 按这几条重做的第二版，作者满意了。

## 换内容的地方

- 截图：放进 `public/<片子名>/img/`，量出每张图上"要拿起来的那几条"的像素框（放大加网格读，不目测）。
- 关键词：只用口播里说到的词；粗宋体 2–5 个字，便签写补充。
- 价签、卡片、清单：数字和标签全部来自口播或素材，不编。
- 配乐和音效：见 `references/bgm.md`、`sound-library.md`。

## 红线

- 不压暗、不加黑幕；人只做整幅等比缩放（在手机里），不裁脸。
- 截图上别人（买家、粉丝）的头像、昵称一律打码；只放聊天内容，App 顶栏和店铺栏裁掉。
- 不旋转画面、不整屏动态模糊、不在大世界里飞镜头。
- 一个画面只跳出一样；跳出来的必须是这句话说的那条。
- 字的右边别超过 x=1032，贴边会被挑出来。

## 用过的片子

- 一条讲副业的竖屏日常分享（127 秒）：第一版（人满屏 + 卡通手写字 + 拍立得 + 奶油卡）被说"不够惊艳"；第二版（大桌面上一镜到底飞镜头）"看不清楚，也找不到重点，晕头转向"；第三版（桌面不动、东西换上来）"行是行，但总觉得差点味道"；第四版加了证据跳出来和配乐音效，作者认可。
- 一条 4 分钟的竖屏分享：只填模板的版本"太重复"；按《锁死的和要拧的》排旋钮、6 个高点现做后，作者满意。
