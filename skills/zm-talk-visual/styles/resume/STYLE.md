# 简历（讲本事是怎么攒出来的）

- **给用户**：整条片子就是一张简历表。你一路的经历一行行填进去，每段练出来的本事盖成一枚章，你在右上角的照片格里，说到要对观众说的话，照片格就放大成满屏。
- **给 AI**：整条片子发生在一张中文表格式的个人简历上（纸色底、藏青表格线、帽子橙强调）。人在右上角的照片格里，对观众说话、提问、讲心里话时放大成满屏，讲经历和证据时缩回格子；经历一行行手写进"工作经历"，本事盖成橙色小章；截图当回形针别上来的附件。文案是讲一段段经历怎么变成今天的本事、给实习生和打工人讲成长、职场建议时用。素材很少也能撑（原片 4 分半只有 3 张截图）。证据截图很多、口吻是日常分享的用书桌；横屏、讲成绩和证据为主的用笔记本；演示软件的用操作台；没有"一段段经历 / 一条条要点"可以往表里填、全靠人和情绪撑的不适合。
- **ID**：`resume`（文件夹名，定了不改）。取名规则见 `references/style.md`《风格卡取名》。
- **画幅**：竖屏 1080×1920。
- **状态**：实验中。在两条竖屏口播上用过（一条讲自己一路的经历怎么变成本事、一条讲做成一个小项目的过程）。

## 和相近的几套怎么二选一

| 想选 | 看什么 |
|---|---|
| 简历 vs 书桌 | 书桌是"拿出证据给你看"：每一拍换一张截图，靠截图撑；简历是"把一路的经历填成一张表"：前面填的格子、盖的章一直留着，后面能回头连线、翻面。截图多、日常分享 → 书桌；讲经历怎么攒成本事、截图少 → 简历 |
| 简历 vs 笔记本 | 笔记本讲"做成了什么"：一张张独立的卡，章节用路线图；简历讲"一段段经历怎么变成本事"：一张表一直往上叠。横屏、成绩和证据为主 → 笔记本；竖屏、成长线和职场建议为主 → 简历 |

## 一句话意象

一张正在填的个人简历：经历一行行写进去，本事一枚枚盖上去，最后整张装进信封带去下一家。

## 意象怎么来的

原片讲"我这个能力是怎么来的"：实习时做客服 → 自己开网店 → 做销售 → 做自媒体 → 现在的副业，一段段经历攒成本事；后半段劝实习生"别只拿多少钱就只干多少钱的活"。口播里本来就有"你的简历和作品集上都可以放上这些经验""填表格""员工变成组长""换家公司"。所以整条片子就是一张简历表。检查过装不装得下：章节 = 表格栏目；人 = 照片格；截图 = 附件；数字 = 填进格子的手写数。

## 招牌动作

1. **照片格 ↔ 满屏**：全片唯一的大镜头动作。纸从下面推上来，人整幅缩进右上角的照片格；对观众说话时照片格放大回满屏。不旋转、不整屏模糊、不一直飞。
2. **本事是"盖"进去的**：每段经历练出来的本事是一枚橙色细框小章（`SkillTag`，1.8 倍砸下来、带一点模糊落定）。全片同一个动作，后面可以把这些章收成一页、拉线连到"现在"。
3. **一张表一直往上叠**：填过的格子、勾过的框、盖过的章都留着，后面的场在它上面接着长（回头连线、翻到背面、装进信封）。这是它和书桌、笔记本最大的不同。
4. **换栏目是翻页**：只有下半张（栏目区）像夹板上的表一样往上翻，表头和照片格不动。
5. **截图是附件**：回形针别上来，说到哪条就把那条原样拿起来放大，其余退成纸色（不压暗）。

## 锁死的和要拧的

锁死（不拿来变）：纸色 + 藏青线 + 一种强调色；人只有满屏 / 照片格 / 附件角三种，整幅等比缩放；换栏目是翻页；字幕在下方一格里。

要拧的六个旋钮在这套里的样子：

| 旋钮 | 可以拧成 |
|---|---|
| 主体 | 手写填格 / 勾选框 / 章 / 附件截图 / 数字 / 对比条 / 单据（工资条、报销单、文凭）/ 人脸 |
| 大小 | 一格 / 一行 / 整张表 / 弹出卡 / 附件放大满宽 |
| 来法 | 笔写出来 / 勾上 / 章砸下来 / 回形针别上来 / 划掉原位改写 / 翻页 / 翻到背面 |
| 节奏 | 一串快勾 / 停住读截图 / 突然安静 |
| 人 | 满屏 / 照片格 / 附件角 |
| 声 | 笔写 / 笔打勾 / 盖章（木棍重击、箱子落地）/ 翻页 / 纸卡落定 / 静 |

## 换内容的地方

1. 表头四行写什么（示例是姓名、想说的、适合谁、现在）：从这条口播的主题来，"想说的"那一格写这条片子要回答的问题。
2. 工作经历那几行：换成这条口播里说到的经历；没有经历线的内容，把下半张换成别的栏目（要点、步骤、自我评价……），一条一格。
3. 每段练出来的本事（章上的字）：只用口播里说过的词。
4. 高点现做：这条片子最重的两三句，在这张表上现做一个新场（原片做过：连线到"现在"、翻背面变"老板评估表"、"非伯乐"大章、装进"下一家"信封；另一条做过：价签划掉改价、五枚章收成"闭环"、消息红点淹没整张表）。**只往表里填格子会是这套的调调，不算做好。**

## 红线

- 不压暗、不加黑幕；人只做整幅等比缩放，不裁脸。
- 表里填的只用口播里说过的词；口播没说的格子用灰条，不编经历、数字、单位名。
- 一行最多填它放得下的字数；放不下换短说法或换小一号，不让字溢出格子。
- 截图别上来时后面的表退成纸色，不压暗。
