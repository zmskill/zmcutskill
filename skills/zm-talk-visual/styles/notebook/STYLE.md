# 笔记本（讲自己的经历和成果）

- **给用户**：要讲自己的经历、踩过的坑、做出的成绩，手上有截图、照片或数字，就选这个。
- **给 AI**：暖白纸面上，截图和卡片跟着讲到的内容一张张落下又收走，人在满屏、左侧小窗和卡片之间切换。文案主要在讲个人经历、踩坑、步骤或成绩，并且有真截图、照片或数字时使用。讲软件操作、需要暗场或科技氛围，或者几乎没有素材时不用。
- **ID**：`notebook`（文件夹名，定了不改）。取名规则见 `references/style.md`《风格卡取名》。

## 一句话意象

暖白纸面上，一张张白卡片落下来又收走，像在翻一本笔记。

## 适合 / 不适合

- 适合：讲经历、讲踩坑、讲步骤、讲成绩；素材多是截图、笔记、图片、数字。
- 不适合：讲软件怎么操作（画面离内容太远，用操作台那一类）；需要暗场、科技氛围的片子。
- 需要的素材：真截图、真照片。没有素材时，全靠卡片里的字撑，会闷。

## 值（`styles/notebook/values.ts`；`Kit.tsx` 的 `LK` 从这里读；用户想换配色、字体就改这个文件）

- 底：`#fdfaf5` → `#f6f0e6` → `#efe6d8`（暖白，有轻微纸纹和光斑）
- 卡片：`#fffdf9`，渐变 `#fffefb → #faf5ec`，暖色软阴影（`cardShadow`，阴影色 `#3a2a18`）
- 字：墨色 `#1d212b`，次一级 `#5b5f6b`、`#9c9a98`
- 重点：橙 `#f0672a`；高亮黄 `#ffdc7a`；辅助蓝 `#2f6db5`、红 `#e5432d`、绿 `#2f9e6b`
- 字体：苹方 / 思源黑体（`SANS`）
- 动效：卡片弹出、上移出现，缓动用镜头库 `Polish` 里的那几条

## 代码

- 外壳 `Shell`（背景、人物缩放、章节标签、字幕）、舞台 `Stage`、白卡 `Card`、截图卡 `Shot`、两侧卡 `SideL / SideR`、画圈 `Ring`、气泡 `Bubble`、关卡地图 `MapPanel / PitOpen / PitDone`：都在 `_koubo-kit/Kit.tsx`。
- 录屏卡 `RecCard`、手画圈 `HRing`、章节路线图 `RouteMap / ChapterOpen`：`_koubo-kit/Notebook.tsx`，样片 composition `nbtest`。
- 口播版镜头：`_koubo-kit/KouboShots.tsx`。
- 现在 `Kit.tsx` 就是这套样子，不是中性零件。用别的样子时不要直接复制它的外壳。
- 这套的内容本来就是每段自己传进外壳的（字幕、章节标签、人物视频路径），外壳里没有写死上一条片子的内容；关卡地图里人物的名字是 `MapPanel` 的 `who`（默认"小白"），终点小旗上的字是 `goal`（默认"终点"），都要换成这条片子的。
- 新片子：复制 `Kit.tsx`、`Notebook.tsx`、`KouboShots.tsx` 到 `remotion/projects/<片子名>/`，照 `Example.tsx` 写各段。

## 招牌动作

- 人物几种状态：满屏；缩成左边带圆角的窗、右边空出舞台；演示录屏时缩到左下角的小窗（`'mini'`），右边一张大录屏卡；一排卡里的一张。
- 右边舞台上，卡片一张张落下来，说到哪张哪张出现；真截图整张给，在说到的数字上画圈。
- 字幕是白底圆角胶囊，压在下方。
- 章节用地图：讲踩坑用关卡地图（`MapPanel`，推近到第几关）；讲几步做成一件事用路线图（`ChapterOpen`，"我"走到第几站，最后走到终点）。站名、终点都换成这条片子的。
- 讲软件怎么用的句子：录屏放进录屏卡，说到哪推近到哪，用手画圈圈住说到的按钮或数字。

## 换内容的地方

舞台上的卡片和截图、章节地图上的关卡名或站名和终点、录屏卡里的录屏和圈的位置、两侧卡、字幕。

## 红线

- 不压暗、不加半透明黑幕；人物只做整幅等比缩放，不裁成大脸。
- 亮的房间配白卡片和深色字。
- 全片一套：别在中间换成暗场。

## 用过的片子

- 第一次用在一条 7 分钟的横屏口播（讲自己从零到做出成绩的经历），全片被认可。
- 之后从风格库挑这套做过一条讲剪辑工具的全片，创作者认可。
- 注意：每条都直接套这套，片子会长得一样。它不是默认样子，开工要先问样子从哪来。
