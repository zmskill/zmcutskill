# 风格库

做出来、在真实片子上被认可过的样子。怎么挑、怎么用、怎么入库，见 `references/style.md`。

名字按 `references/style.md`《风格卡取名》取：意象名（用途）。

| 文件夹 | 名字 | 一句话意象 | 适合 | 不适合 | 第一次用在 |
|---|---|---|---|---|---|
| [notebook](notebook/STYLE.md) | 笔记本（讲自己的经历和成果） | 暖白纸面上一张张白卡片，像翻笔记 | 讲经历、讲踩坑、讲步骤、讲成绩；素材多是截图、照片、数字 | 讲软件怎么操作（画面离内容太远）；需要暗场氛围的 | 一条讲个人经历的口播 |
| [workbench](workbench/STYLE.md) | 操作台（讲软件怎么用） | 整条片子是一个正在用的软件，人在监视器里 | 讲某个工具或软件怎么用、讲做东西的过程；手上有录屏 | 和软件无关的话题（硬套像在演戏）；没有录屏或界面素材 | 一条讲配乐的口播 |

样片在各自的 `样片/` 文件夹里。
