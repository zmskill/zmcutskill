# 音乐总指挥与节拍闭环

> BGM 决定整条片子的情绪、段落长度、运镜速度与音效密度。不是"剪完画面再找歌配"，而是**先摸透这首歌，再按歌搭结构、钉同步点、排画面**。

---

## 一、选歌边界与定档

- **本项目不带任何音乐**：由用户提供有授权的 BGM。用户没有现成歌时，将 `assets/audio/bgm/去哪找歌.md` 中的平台与注意事项发给他挑选。
- **情绪档位由你自主定夺，不问用户**：内部分**燃 / 中 / 松**三档，判断依据按优先级：① 用户随口描述（如"温柔一点""要有劲"）→ ② 歌名与来源页风格标签 → ③ 产品与成片目标气质 → ④ 算法量出的数值（仅作参考）。
- 定好后用一句大白话告知用户你的剪法（例："这首歌我按轻快有节奏感来剪，镜头飞得利落、重拍干脆切"），不说"燃/中/松"，不等回答直接推进，并把判断依据原文传给 `zm_music.py --feel "..."`。

---

## 二、音乐分析、反拍校验、剪歌与实测拍点

按以下顺序运行工具链（仅需 Python + numpy + ffmpeg）：

```bash
# 1. 检测拍点、小节、能量与炸开点（内部含等距网格最小二乘线性回归拟合，防单点 BPM 漂移）
python3 $SKILL/tools/beats.py 歌.mp3 --out analysis/beats.json

# 2. 校验拍子格子有没有认到反拍上（只量打算用的那一段）
python3 $SKILL/tools/zm_beat_phase.py 歌.mp3 --beats analysis/beats.json --out analysis/beat_phase.md
# 若报"格子歪了"，按提示偏移修正并重跑到通过，再往下走！

# 3. 音乐画像：输出情绪三数（兴奋度/满空/明暗）、音乐结构表与同步点建议数
python3 $SKILL/tools/zm_music.py 歌.mp3 --beats analysis/beats.json --feel "你的判断依据原文" \
  --offset <起点秒> --len <目标片长秒> --out analysis/music_profile.json
```

### 什么时候必须剪歌？
查看每小节能量分布，若**音乐满起来之前**的开头安静段占比超过档位上限（燃 25%、中 40%），或高潮来得太晚，必须在小节线上剪歌（片尾歌自然收住留给落版的小节不算在开头安静段里）：

```bash
python3 $SKILL/tools/cut_song.py 歌.mp3 --beats analysis/beats.json --list
python3 $SKILL/tools/cut_song.py 歌.mp3 --beats analysis/beats.json --take 14-16,20-28 --out audio/music.wav
```

- 剪歌只在小节线切，带短交叉淡化防咔哒声；剪完后用生成的 `audio/music.beats.json` 重新跑 `zm_music.py`；请用户试听一下剪接接口是否自然。

### 实测每拍真实响点（生成 `hits.ts`）
歌剪定后，直接从成片音轨波形实测每一拍真正起音的时刻，避免理论网格与真实鼓点偏差：

```bash
python3 $SKILL/tools/zm_hits.py audio/music.wav --beats audio/music.beats.json --out analysis/hits.json
```

该命令会同时生成 `analysis/hits.json` 和 `analysis/hits.ts`。将 `hits.ts` 拷入工程 `src/`：
- **`onF(拍号)`**：比实测响点早 1 帧，用于所有**画面事件**（切点、镜头最快帧、进场鼓包顶点）；
- **`hitF(拍号)`**：实测响点所在帧，用于所有**音效与音乐让开**。

## 三、三档剪法参数表（全按「拍」算，适配任意 BPM）

| 参数 | 燃 | 中 | 松 |
|---|---|---|---|
| 主节奏格 | 半拍一格 | 一拍一格 | 两拍一格 |
| 满段单镜长度 | 2–4 拍 | 4–8 拍 | 8–16 拍 |
| 静段单镜长度 | 4–8 拍 | 4–8 拍 | 8–16 拍 |
| 满段每小节至少画面事件数 | 4 | 2 | 1 |
| 满段读字镜头放慢上限 | 1 拍 | 2 拍 | 不限 |
| 音乐满前安静段上限 | 25% | 40% | 不限 |
| 转场节奏 | 飞过去/速度接力硬切，切密飞快 | 同左，切得适中 | 同左，每小节最多 1 次，缓飞、旋律换句切 |
| 整屏特效（泵/闪/震） | ≤3 处（钉最强拍） | ≤2 处 | 不用 |
| 音效材质 | 短、硬、干、有分量 | 干净拟音为主 | 轻、软、带尾音、无重击 |
| 同步点数（每 30 秒） | 6–12 个 | 4–8 个 | 2–5 个 |

- **画面事件**指观众可见的一次状态变化（进场、切换、点击、高亮、换字、硬切），不包括纯背景慢推。
- 某条片子若需偏离默认值，在设计 spec 写明原因即可。

## 四、按音乐结构排布故事与总谱

1. **故事顺序不变，段落位置听音乐的**：
   - **满的小节**放事件最密的内容（登场、功能演示、证据连打、列举）；
   - **歌收住的小节**放需要读清的画面（成果特写、品牌落版、金句）；若必须在满段看成果，靠慢推 + 页内滚动 + 逐拍高亮保持每拍有动感；
   - **魔法瞬间**钉在音乐炸开第一拍或最强重拍上，前面留半拍到一拍蓄力空当。
2. **零件合拍评估与起点对齐**：
   - 挑零件前先跑 `python3 $SKILL/tools/zm_fit_parts.py --bpm <BPM> --mood <档位> --use <用途>` 并把输出存为 `analysis/fit_parts.md`；
   - 零件按原速一口气播完不冻帧，靠挪起点把主落点对到拍上：`起点帧 = onF(拍号) − (落点帧 − 零件起始帧)`。
3. **写总谱（设计 spec 的 `## 总谱`）**：一行一个画面事件（至少每小节一行），代码里的镜头表、音效表、字幕表全从总谱抄，一律用 `onF()` / `hitF()`，绝不手写帧号：

| 小节 | 拍 | 帧 | 音乐这里是什么 | 画面事件 | 镜头 / 零件 | 接 | 音效 | 同时几层 |
|---|---|---|---|---|---|---|---|---|
| 5 | 16 | 329 | 满 · 炸开第一拍 | ★同步点 · **魔法瞬间**：结果页冲入展开（预备/夸张/跟随） | S5 result-page-tilt-scroll | 卡拍硬切（速度接力） | 落版重击（音乐让开 6 dB） | 2.5 |
| 5 | 17 | 350 | 满 · 底鼓 | 连打 1/4：大字数字跳出 | 同上 | — | 升调短音 | 2.5 |

- 先填「音乐这里是什么」（抄自音乐结构表），再填画面、接法与音效；
- 同步点标 `★同步点` 且必须配音效；连打段标 `连打`；
- **同时几层**：满段音乐算 2 层、静段算 1 层，每个音效算 0.5 层，**严禁超过 2.5 层**。

## 五、渲后闭环量片与音画同步回测

成片（及半尺寸小样）渲染后，必须跑十项自动化量片检验：

```bash
python3 $SKILL/tools/zm_film_check.py \
  --film out/promo.mp4 --nobgm out/promo-nobgm.mp4 \
  --beats audio/music.beats.json --offset 0 --mood <档位> \
  --cues audio/音效清单.json --cuts <切点帧号逗号列表> \
  --out reviews/量片报告.md
```

同时核查音视频封装的物理同步误差：
- **AAC 编码延迟**：FFmpeg/Remotion 导出 AAC 音轨通常带约 1024–2048 样本（30fps 下约 1–1.3 帧）的编解码预热偏移，回测抽音轨比对实际瞬态峰值与目标拍点，区分"音频轨自身偏移"与"视觉切点误差"：切点相对拍点误差理想 ≤1.5 帧、合格 ≤3 帧。
- 量片十项底线（满段动感、开头安静占比、同步点分量、切点两侧动态、主体占比、开头 2 秒、不破音、连打分量、糊着换次数、顿挫检测）必须全部通过，才能进入独立终检。
