# 声音设计与本地音效库

> 音乐和音效是同一个听觉系统。**先由音乐定哪里需要响、响多重、什么音色，再挑音、算音量、对齐物理延迟。**

---

## 一、音乐与音效一体六条

1. **满段少而重，空段顶节奏**：音乐满段鼓点已经很密，每小节只给最关键的 1–2 下配音；音乐安静段或停顿处，用轻快的拟音（打字、点击、落定）按拍撑住节奏。
2. **同时响不超过 2.5 层**：满段音乐算 2 层、静段算 1 层，每个音效算 0.5 层。同一拍同时叠两三个音效必然混浊——删一个或错开半拍。
3. **用「最响起音点」对准 `hitF`，画面早 1 帧用 `onF`**：
   - 重击、落定、点击、tick：声音最响峰值对准 `hitF(拍号)`；
   - 运镜风声（whoosh）：最响处对准**镜头速度最快的那一帧**（不是起步帧），长度匹配飞行时长；
   - 上扬铺垫（riser）：**到顶 = 下一个重拍**，倒着往前铺 1–2 拍；
   - 音效触发帧一律从代码里算（镜头最快帧、切点、鼓包顶点），不凭感觉估。
4. **音量按「比这一刻音乐高多少 dB」计算，绝不手填**：
   ```bash
   python3 $SKILL/tools/zm_sfx_levels.py audio/音效清单.json --music audio/music.wav --music-vol 0.5 --write
   ```
   它在每个音效主频段里与同一时刻 BGM 对比：有分量重击高 +8 dB、东西到了/真实动作高 +5 dB、运镜/铺垫高 +4 dB。若算出音量需 >1.6 才听得清，说明频段和音乐撞车（如低音满段又塞低音轰），直接换不同频段的音色。
5. **只在同步点让音乐让开（`duck()`）**：用 `assets/lib/helpers/mix.ts` 的 `duck(f, HITS)` 在核心同步点压低音乐约 6 dB、半秒内恢复；非同步点绝不滥用让开。
6. **屏住一拍看歌势**：魔法瞬间前留半到一拍蓄力——歌自带停顿顺着用；歌正在蓄力过门冲刺则**绝不掐音乐**（只在画面慢下来、微暗）；歌平走无停顿才可用 `gap()` 短掐半到一拍（全片最多 1 次）。

## 二、声音设计底层原理（拟音、防机枪感、物理延迟与混音）

- **按片种和动作材质选音色**：产品宣传片追求电影级与真实物理质感（纸、玻璃、金属、机械开关、真实键盘、干净气流），**禁用卡通/游戏提示音色**（本地库里 `08_人声`、`09_趣味` 及游戏感提示音一般不用于产品宣传片）。
- **每个动作有自己的声音**：不要全片一个提示音用到底。按档位选材质：
  - **燃**：硬、短、干（金属、重击、短甩、机械锁定），满段每小节 1–2 个，静段 2–4 个；
  - **中**：干净的真实动作拟音（纸、卡片、键盘、开关），每小节 1–2 个，重击 ≤1 处；
  - **松**：轻、软、带自然尾音（气息、轻 chime、水、纸），每小节 0–1 个，不用重击。
- **拟音裁至与动作等长**：飞镜、拖拽、进度条等连续动作，音频有效时长与画面动作严格匹配，超长尾音做干净淡出。
- **连发防「机枪效应」（Round-Robin）**：连续出现多次的同类动作（卡片连发、打字、逐条弹出），准备 2–3 个微差变体交替使用，并做**升调递进 / 音量微幅梯度 / 间隔微加速**，避免同一音频同响度机械复读。
- **经典转折句式**：全片高潮或大转折可用 `Riser（铺垫上扬）→ Impact（重击落拍）→ Tail/Sparkle（余韵亮音）` 三段式收束。
- **音画对齐必须扣除两项物理偏移**：
  1. **音源起音峰值滞后**：音频文件开头往往有几十毫秒起音爬坡，必须按最响峰值点提前摆放（本地库 277 个文件已预量好 `对齐点` 直接乘帧率即可，仅在裁切/变速/倒放后重测）；
  2. **编码管线输出延迟**：AAC 封装与渲染管线可能带来约 1–1.3 帧固定延迟，在成片回测时抽音轨实测核对。
- **广播级响度标准化 + 双轨输出**：
  - 成片统一过 −14 LUFS 响度与 −1.5 dBTP 真峰值限幅（带 BGM 与不带 BGM 两版都过，防破音、保证多平台音量一致）：
    ```bash
    ffmpeg -i out/promo_raw.mp4 -c:v copy -af "loudnorm=I=-14:TP=-1.5:LRA=11" -c:a aac -b:a 320k out/promo.mp4
    ```

## 三、选音来源顺序与本地音效库（277 个）

按顺序选音：**用户指定 → 本地音效库 `assets/sfx-library/` → 代码合成 `tools/zm_sfx_synth.py` → Freesound 兜底**。

1. **查本地音效库（录音优先）**：
   - 先看 `references/sfx-kinds.md`（22 类用途与目录索引），再查 `assets/sfx-library/音效库记录.md`（程序读 `音效库记录.json`，含时长、对齐点、响度、用法与过往评价）；
   - 录音优先于合成，优先挑标有"常用"的；没被听过的新选文件在清单里注明，请用户试听；
   - 选定文件复制到片子工程 `video/public/audio/sfx/` 供 Remotion 加载，在清单里记录库内相对路径与许可。
   - **许可说明**：库内 58 个为 CC0（公共领域），219 个来自 Sonniss GDC 2026 免费音效包（免版税可商用，不得原样出售或用于训练 AI，原协议见 `assets/sfx-library/Sonniss-GDC-License.pdf`）。
2. **库里没有合适音色 → 先用合成工具**：
   - `python3 $SKILL/tools/zm_sfx_synth.py` 可快速生成升调短音串、匹配时长的飞镜风声、下沉低音、上扬铺垫、收尾亮音、低频蜂鸣、干脆点击等。
3. **仍不满足 → Freesound CC0 兜底**：
   - 用 `assets/scripts/sfx-source.py` 搜索并下载 CC0 许可的真实录音（默认 `--license cc0`，搜索词写具体物理动作与材质而非抽象情绪词，最多翻 3 页，下载后实测有效时长、峰值对齐点与响度，试听确认后接入）。

## 四、片子音效清单、试听页与经验回库

每条片子维护 `audio/音效清单.json`（一行一个触发点）：

```json
{
  "片子": "某产品宣传片 v1",
  "音效": [
    {
      "时间": 6.42,
      "拍": 16,
      "对着": "magic-moment",
      "画面": "魔法瞬间结果页落定",
      "为什么配": "有分量",
      "类别": "落版重击",
      "文件": "补缺/26_落版重击/预告片大轰214_effectivetrailer-booms-v.wav",
      "音量": 0.55,
      "让音乐让开": 6,
      "同步点": true,
      "用户反馈": ""
    }
  ]
}
```

- `为什么配` 只填五种之一：`运镜转场 / 东西到了 / 有分量 / 铺垫 / 真实动作`，填不出来就不配；
- 交片时生成逐条试听页一并交付：
  `python3 $SKILL/tools/sfx_cue_page.py audio/音效清单.json $SKILL/assets/sfx-library reviews/音效试听.html`
- 用户听完反馈后写回清单，可用 `python3 $SKILL/tools/sfx_library.py usage $SKILL/assets/sfx-library audio/音效清单.json` 汇总使用经验回库。
