# 音效类别表（2026-11-20）

镜头组的音效清单只写"这一下要哪一类声音"（`type`）和"具体是什么"（`note`），**不写死文件**。
做片时按类别去音效库 `assets/sfx-library/` 里挑，同一条片子里同一类声音统一用一个文件。
代码里的类别清单是 `assets/lib/helpers/groupClock.ts` 的 `SFX_KINDS`，写错类别编译和 `checkContract` 都会报错。

怎么挑（详见 `sound-and-sfx.md`）：

1. 按下表找到这一类在库里的位置，在 `音效库记录.md` 里看"它是什么"和"还能当什么用"。
2. 先看"你的评价"是"常用"的；**录音优先**，库里录音都不合适才用标"合成"的。
3. 材质尽量和画面一致（纸卡配纸、金属面板配金属）；调性和配乐一致（真歌 + 克制，见判例 S6）。
4. 库里没有合适的：按 `sound-and-sfx.md` 去 Freesound 找，好用的补回库。
5. 某个镜头组的某一下，用户看片说好了，才把文件写进它合同的 `file`。

对齐是库记录里每个文件自己的"对齐 / 对齐点"（开始播放的时间 = 画面那一刻 − 对齐点）；上表只是通常情况。

**要加新类别时**：同时改 `SFX_KINDS` 和这张表，再跑编译检查；不要为一两个镜头加类别，先看能不能归进现有的。
