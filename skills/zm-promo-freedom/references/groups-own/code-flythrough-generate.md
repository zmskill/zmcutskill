## 动作谱
- 【镜头组】code-flythrough-generate：镜头穿过漂浮的绿色代码关键词和霓虹四角星（有景深）→ 中间浮出深色玻璃输入条逐字打一句提问 →
- 镜头往后拉，关键词淡掉，露出输入条上面的产品名和一圈圈圆角描边 → 硬切大特写：输入条右端的发送键 + 打出「生成」，边缘蓝绿流光，背景点阵闪起来（036-A 一串，核心）
- 学的动作（Varcyyyy · BLACKBOX 0–7s，30fps 逐帧量过）：
- 0–1.5 镜头往前穿过关键词（近的大且糊、远的小且糊，焦点在中间那层），1.4 输入条在中间淡入（995×119，480..1475，y512..631）
- 1.95–3.0 逐字打字（字 43px），3.4–3.8 关键词变糊、淡出，镜头微微拉远；3.7 产品名出现在输入条上方（y450），三圈圆角描边（305–1622 / 160–1778 / 2–1920 宽）
- 5.0 硬切：输入条右端特写（高 360，右端 x≈1170），白色圆键 240px（1020,540）；5.1–5.5 左边打出 140px 的字；
- 5.0→7.0 镜头慢慢往左上带（圆键 1020,540 → 960,450）；边缘上蓝下绿发光；6.1 起右边浮出一片绿色点阵闪烁
- 我们的内容：提问「这段代码怎么优化？」，按钮字「生成」；产品是虚构的「码匣 AI」（图标自己画），画面右下角标"虚构 · 仅作演示"。

- 【未做】上限文案验证（第 3.5 步）：用户 2026-11-21 选了直接入库，没渲 preview-max.mp4；第一次用进真实片子、换文案前要先补。
- 【check7】原片 0–7s。关键词有景深（近糊远糊）；发送键特写边缘蓝绿光，背景点阵闪。
- 【check12】流畅度修正：切点对齐原片 4.867s（之前晚 4 帧）；切之前整条输入框往左慢慢漂（之前停住）；特写里发送键从右边滑进来；「生成」提前到 5.08 开始打；背景点阵提前到 6.0。
- 【check13】复刻修正：飞越代码那段背景的绿光跟着光圈一起亮；特写里背景是青绿渐变 + 左上 / 左下两团光（位置吸管量过），输入框描边和发送键的光加强。
- 【check14】按钮和边框：玻璃胶囊 + 一圈会走的绿 / 蓝光（光沿边绕、底边一道绿光扫过）；按钮做成立体珠子（暗槽、彩色辉光跟着光走、按下会缩）；字逐个由糊变清；飞进代码的镜头速度按原片。
- 【check16】按钮点击：原片键是直接坐在输入条右端一圈宽蓝边带里的白色圆珠（没有暗凹槽）；6.8–7.0 被按下时顶边出一道白高光、底部陷下去一弯灰影、左边映出青绿光、整颗键缩一点糊一点。照着做了，并补上那圈宽蓝边带。
- 【check17】第5秒点击：原片在 4.9–5.8 秒有一道亮绿光贴着按钮边缘顺时针绕一圈（右 → 下 → 左），那就是「被点中」的反馈，之后才出蓝边带。之前我们只做了 6.8 秒的按下，第5秒是空的。现在补上这道绕圈的绿光，蓝边带推迟到 5.85 秒才出。
- 【check18】按你截图那一下：逐帧量了原片按钮的大小——5.93 秒开始按下，6.03 秒缩到原来的 84%，然后弹回来，6.4 秒略大一点（101%）停住，整个约 0.45 秒。我们按同一条曲线做，逐帧对比大小误差在 1–2 像素内。之前把 6.8 秒镜头拉走时的变小误当成了按下，所以一直不对。另外把右端蓝边带和键边的亮圈调淡，更接近原片。
- 【check19】按完之后的光扩散：原片按下的同时，从输入条边缘往外推出一圈圈「点阵被点亮」的波纹，像雨滴落进水里——5.93、6.25、6.55 各一圈，一圈比一圈弱；波扫过的地方点阵留着微亮。点阵也改成原片的菱形格、越远点越大；输入条周围的青光在按下后越来越亮。之前点阵是 6.0 秒整片一起淡入，没有波纹。
