## 动作谱
1. 斜俯视格子地图，蓝色彗星线沿格子冲进来、拐上去到第一个地点，身后格子亮起
2. 镜头转正成俯视，紫粉线从第一个地点往右、拐两个弯到第二个地点
3. 镜头扎近，线头鼓成胶囊、变成搜索框，框里打字
4. 搜索框缩小、往后一翻
5. 开始是一张空地图 → 路线一段段画出来 → 变成一个"搜索目的地"框（接下一镜）

## 意图
斜放的网格地图上一条彗星路线从家出发、拐弯走到第一站，再换一条品红路线走到第二站，经过的格子亮成蓝色；镜头一路推近，最后变成一个搜索框——学的是原片这一拍的动作和节奏，内容换成「小周」出行。

## 动效核心
见动作谱；逐帧数字全在逐元素时间表和代码常量里（代码顶部有拍表和毛病清单）。

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 镜头 | E_CORNERS 逐帧四角（ECC） | 命门：斜放 / 透视全是逐帧量的四角（ECC 同形配准），不许改成 rotateX/Y/Z 凑角度 |
| 路线头 | D1 / D2 弧长关键帧（把原片路线头反投影回平面量的） | 命门 |
| 格子 | 比路线头晚亮：第一段 140px、第二段 60px |  |
