## 动作谱
1. 白 → 品牌蓝，中间一团很虚的白方块光收成毛玻璃方块
2. 方块里的白色笔画一段段"长"出来：短横条从拐点拉出（端头鼓一点）→ 长臂往右上长成勾 → 一颗点从左上画外落进来（带一点回弹）
3. 四周零星青柠星一闪一灭；图标缩到一半、往左让，名字从图标后面逐字往右抽出
4. 标语逐字（后半强调色斜体）→ 按钮从小弹出（带回弹）→ 网址逐字
5. 光标从下方滑进来停在按钮上 → 按下 → 两圈白描边依次往外扩、变淡，右上一颗小星 → 光标淡出
6. 品牌落版静看（背景光慢漂、全程极慢推近）
7. 声音：硬切 thump、笔画黏连声、点落 pop、名字 whoosh、逐字 tick、按钮 pop、点击、描边 chime
8. 开始是一片白 → 标志在眼前长出来、名字和一句承诺跟上、按钮被按下 → 停在"该去试一试"的落版上

## 意图
标志"长出来"比淡入更有记忆点；按钮被真的按一下，把"行动号召"演出来，而不是摆在那里。

## 动效核心
- 笔画是描边长度 + 端头圆滴长出来的，不是淡入（独有）
- 名字从图标后面抽出（图标盖在名字上层），不是从空中淡入（独有）
- 两圈描边晚 0.12s 依次扩，越往外越淡（独有）

## 已知坑
- 原片标志是它家的 T 形标（横条下滴成竖杆、再长出勾），我们没照抄，换成"勾 + 点"，保留"一段段长出来 + 点从画外落进来"的手法
- 原片的笔画长出带明显的液体黏连（鼓包、拉丝），我们只做了端头鼓一点；要更"液体"得用 SVG 滤镜做 gooey，暂没做
- 传真标志（logo 输入）时没有"长出来"的动画，只跟着方块一起出现
- 落版段活动值 0.1–0.2（原片同样），靠背景光慢漂 + 推近保持不冻
