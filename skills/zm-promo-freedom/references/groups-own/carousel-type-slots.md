## 动作谱
1. 贴脸的页面拉远摆正，变成轮播里的一张卡
2. 轮播一下下往左甩，空出文字框
3. 大字逐个蹦进来 + 角上小字升起
4. 再甩，第二句：小字打字、大字升起 → 甩出去接 logo

## 意图
贴脸的斜放任务页猛地拉远摆正，变成横向轮播里的一张卡；轮播一下下往左甩，文字框里大字逐个蹦出"一眼看清 / 全家的"，再甩到第二框"大事 / 小事"——学的是原片这一拍的动作和节奏，内容换成「小周」全家任务。

## 动效核心
见动作谱；逐帧数字全在逐元素时间表和代码常量里（代码顶部有拍表和毛病清单）。

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 拉远 | 页面卡四角逐帧（track.ts） | 命门 |
| 甩 | 峰值每帧 121–127px，之间每帧 8–40px 慢漂 | 命门 |
| 文字框 | 52px → 全宽 0.7s，右边的卡被推开 |  |

## 已知坑
- 中文比英文宽，文字框按字宽撑开，框右边的卡比原片早一点被推开
- 远离中间的卡按横向位置做景深虚化
- 字体：云端渲染是 Noto Sans CJK，不是苹方
