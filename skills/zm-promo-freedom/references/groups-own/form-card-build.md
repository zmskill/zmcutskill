## 动作谱
1. 空卡片里只有灰色占位和一个蓝色小圆点
2. 圆点横着撑开成按钮、出字
3. 图标、下拉、日期、标签一样一样从虚到实长出来
4. 四周点阵长条慢慢往外漂，镜头慢推
5. 开始是一张空卡片 → 表单被一样样填出来 → 一张能用的出行表单（接倾倒推进）

## 意图
白卡片在正中长大，按钮从小圆点撑开，表单内容一样样由虚到实填进去；卡片一直慢慢往后仰（上窄下宽），四周是一排排别的表单卡片（点阵按钮 + 淡字）——学的是原片这一拍的动作和节奏，内容换成「小周」出行。

## 动效核心
见动作谱；逐帧数字全在逐元素时间表和代码常量里（代码顶部有拍表和毛病清单）。

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 按钮撑开 | BTN_W 每 1/15s 逐帧量 | 命门 |
| 后仰 | KEY_R 宽度比 1→1.075 | 命门：卡片不是平的，为下一镜倾倒起势 |
| 四周卡片 | CHIP_TRACKS 逐帧位置 / 宽 / 外斜角 | 外侧往外斜、越远越糊 |
