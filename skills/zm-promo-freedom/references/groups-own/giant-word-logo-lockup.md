## 动作谱
1. 准备：超大白字一半埋在白底里，只有蓝光里的下半截看得到（0–0.5）
2. 主动作：大字往左越甩越快、硬切成小字一行，最后一个词擦出（1.07–1.53）
3. 收势：小字加速缩成一个点 → 一个大 logo "砸"下来缩小、两块合拢（1.6–2.4）
4. 让位：logo 往左让，名字字母一个个滑进来；整组缩小、上移，副标题跟上（2.4–4.2）
5. 交接：从左擦掉名字，副标题居中 → 原地换词 → 换成 but（4.2–5.67）
6. 节奏：每一句都是"静 → 越缩越快 → 换下一句"，快慢比约 1:5
7. 开始是"认识一下"的大字 → 新东西是什么（logo + 名字 + 一句话说清是什么） → "但是"（接下一镜）
