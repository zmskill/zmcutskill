## 动作谱
1. 一个巨大的字从左边开始打，越打越小、越居中
2. 新词从右下灰虚着落上来，镜头往左走，旧句从右往左删掉
3. 第二个词同样落定，蓝色小点在周围漂
4. 镜头慢慢拉远，右上亮起一团橙光
5. 开始是"下个周末去哪" → 一句话被改写 → "早就安排好了。"（接光线转场）

## 意图
白底上一行大黑字打出来，镜头推近、平移，前半句掉下去淡掉，只留后半个词，再换成两个词「早就安排 / 好了。」，四周散开几颗彩色小点——学的是原片这一拍的动作和节奏，内容换成「小周」出行。

## 动效核心
见动作谱；逐帧数字全在逐元素时间表和代码常量里（代码顶部有拍表和毛病清单）。

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 推镜 | ZOOM1 / PAN 关键帧逐帧量 | 停留时极慢推近 |
| 掉字 | DROP / OPAC 关键帧 | 命门：前半句是往下掉，不是淡出 |
