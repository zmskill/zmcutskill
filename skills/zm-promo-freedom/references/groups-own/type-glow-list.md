## 动作谱
1. 一行大黑字边打边滑上来，蓝色光标
2. 字缩小、变灰、淡掉
3. 第二句渐变彩字逐字糊入，带柔光，颜色流动
4. 彩字缩小淡掉
5. 小标题 + 两行推荐由糊变清地擦出来，错落上浮，然后上滑走

## 意图
一行大黑字边打边滑上来、缩小变灰；第二句渐变彩字逐字糊入、带柔光、颜色流动；彩字缩淡后，小标题 + 两行推荐由糊变清地擦出来，错落上浮再上滑走——学的是原片这一拍的动作和节奏，内容换成「小周」出行。

## 动效核心
见动作谱；逐帧数字全在逐元素时间表和代码常量里（代码顶部有拍表和毛病清单）。
