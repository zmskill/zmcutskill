## 动作谱
1. 贴脸一行，惯性滑到最右 → 两格整格换色
2. 快滑到左边看人 → 快滑回来 → 再换一次色
3. 整个画面加速往上走

## 意图
贴脸看任务表的一行，整条横着滑到最右，费用、状态两格整格换色；快滑回左边看人，再滑回来状态变"已完成"，整个画面往上走——学的是原片这一拍的动作和节奏，内容换成「小周」全家任务。

## 动效核心
见动作谱；逐帧数字全在逐元素时间表和代码常量里（代码顶部有拍表和毛病清单）。

## 参数表
| 参数 | 典型值 | 调节手感 |

| 横滑 | 帮手列左沿逐帧互相关量的 STRIP 关键帧 | 命门：内容没有拖影，滑块慢半拍且被拉长 |
| 换色 | 整格底色 0.17–0.2s 过渡、中途换字 |  |
