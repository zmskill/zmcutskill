## 下面是镜头卡版的说明（动作和拍表照旧有效）
## 意图
一整句话从头带到尾、没有一次空白画面：观众先读到"需求"，看它变成输入框、被发出去、变成一叠网页，再被一句话和一颗胶囊概括，最后冲进字缝里看到产品名。衔接全靠"同一个点"：框缩进的点就是网页弹出的点，擦除扫到的中线就是胶囊撑开的竖线，胶囊缩没的中心就是星纹长出的中心。

## 动效核心
- 0–0.7s 前 5 个字机械打字（4 帧/字、黑光标不闪），此时整张输入框其实放大了 4.5 倍
- 0.9–2.0s 整框连字从 4.5× 拉远到 1×（锚点在文字左上角，最快 1.4–1.65s）；光标 1.07s 一帧消失，后面的字以约 28 字/秒流式冒出、每个字 0.85s 从浅灰变墨
- 1.95–2.45s 发送钮从灰变成旋转的渐变（+8%）；2.0–3.1s 真停等点击；手形光标右下进、3.72s 按下缩 8%
- 3.87–4.25s 框原地往中心吸（先慢后猛）；4.17s 网页从框心以 3% 宽出现在框前、0.23s 放大 13 倍；之后慢推 1.2s
- 5.63–6.4s 首页往下让开，摊位 / 地图 / 报名三页依次从身后（后出的在更下层）抽出、强缓出散到四角；6.4–7.0s 各自继续外漂 + 慢推
- 7.0–7.4s 相机加速冲进去，四页放大飞出画面；"看见 / 每一个 / 页面"三块各在不同深度先后从中心飞来（"页面"追上时和"每一个"挤在一起），7.4–8.2s 长尾巴减速
- 8.17–8.93s 字原地不动，30% 宽柔边遮罩从左往右擦掉；8.77s 胶囊从中线一根竖线横向撑开（渐变窄时只露中段），三组字从下 25px 依次浮起；9.3–10.2s 真停
- 10.2–10.87s 胶囊（窗口）往中心收得比字快，字两头被切掉；10.53s Logo 四角星平铺描边纹从胶囊背后放大旋转铺满；10.7s 起"隆重介绍"2 帧/字打出（灰、低 1% → 墨）
- 11.05–11.9s 慢推；11.9–12.53s 指数加速冲进"重""介"之间的白缝（约 48 倍），黑字被推出画面
- 12.47–13.07s 产品名 5 个字每 3 帧一个从画面底下升起、0.2s 强缓出、不弹跳，在黑字前面；整词一个渐变 1.2s 转 180°
- 13.3–13.8s 产品名加速缩小 → 13.8s 硬切到 Logo 落版（1.4× 减速缩到 1×，切点缩放速度连续），之后极慢推近停到 15.2s

## 拍表（30fps，帧号；四拍各是单独子组件，单拿时 `<XxxBeat t={frame/30} />`）
| 拍 | 组件 / 常量 | 帧 | 单独用时从哪进 | 停在什么画面 |
|---|---|---|---|---|
| 1 字 → 输入框 → 点发送 | `PromptBeat` / `BEAT_PROMPT` | 0–128 | 第 0 帧：只有 4.5 倍大的"帮"前的黑光标 | 第 116 帧：输入框 + 发光发送钮 + 手指按着（再往后框被吸没，要接一张从中心弹出的画面） |
| 2 网页铺开 | `PagesBeat` / `BEAT_PAGES` | 125–222 | 第 125 帧：3% 宽的首页从画面中心出现（可接任何"缩进中心"的上一拍） | 第 200 帧：四页散在四角、中间留白（第 210 帧起冲进去，四页飞出画） |
| 3 大字擦除 → 胶囊 | `PillBeat` / `BEAT_PILL` | 213–326 | 第 213 帧：字从中心远处飞来（单用时建议从 222 帧进：整行已到位） | 第 300 帧：胶囊"一次全部看完"（再往后胶囊缩成中心一点） |
| 4 冲进字 → 产品名 | `StarLayer` + `NameBeat` / `BEAT_NAME` | 316–456 | 第 321 帧：星纹已铺开、"隆"字刚打出 | 第 420–456 帧：Logo + 品牌名落版（Logo 落版停 1.2s） |

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 开场拉远倍数 | 4.5×，0.9–2.0s | 小于 3× 看不出"原来在框里"；锚点必须在文字左上角 |
| 流式出字速度 / 变墨时长 | 28 字/秒 / 0.85s | 变墨太快就没有"墨水渗开"的左黑右浅 |
| 框缩 ↔ 网页弹出 | 网页在框缩到 0.78 时出现，0.23s 从 3% 到 39% 宽 | 中间不能有一帧只剩白底 |
| 擦除柔边宽 | 30% 画面宽，0.76s 扫完 | 柔边太窄像硬切，太宽像整体淡出 |
| 胶囊撑开 | 8.77–9.2s 从 1.5% 到 51% 宽，之后 1s 慢长到 54% | 必须从竖线长，不要淡入 |
| 冲字缝 | `1.138·exp(3.75·u^3.4)`，0.63s，约 48 倍 | "重""介"之间白缝约 52px，倍数要 ≥ 40 才能整屏变白 |
| 产品名升起 | 每字间隔 0.1s、0.2s 到位、无过冲 | 中文字少，间隔小于 0.08s 阶梯感就没了 |
| 渐变 | 靛紫 #8d86f2 → 天青 → 薄荷 → 嫩绿 #c6f8a6，转 180°/1.2s | 转到竖直方向时整词同色，这是自然的 |

## 声音

## 已知坑
- VM 里用 skill 渲染环境的 node_modules 渲染不了（那是 macOS 版）；Linux 下 `@rspack/binding` 原生包一加载就 Bus error，Remotion 默认的 Chrome 下载地址也不在白名单。这次在 VM 的 `~/r022` 里用 Linux 版 node_modules（把 rspack 改成按需加载）+ GitHub 上的 arm64 Chromium 渲染，`qa/qa.sh`（抽帧检查）、`qa/render_hq.sh`（成片）记录了做法。成片按 2 倍渲染再 lanczos 缩回（等同 --hq）。
- 用 Remotion 的 `<Freeze>` 抽帧检查在这套环境里拿到的帧不对，改成把场景做成 `PromptPagesPillRevealScene({t})` 直接传时间。
- 冲字缝的落点：中文字距小，"重""介"之间的白缝只有约 52px，放大倍数要到 40 倍以上才整屏变白（原片约 10 倍就够）；用 SVG 矢量字，不会糊。
- 原片网页靠食物照片撑画面密度，这里换成色块插画（帐篷、摊位卡、地图、报名券），四页飞散时密度稍低，6.4–7.0s 的活动值约 3（原片 6–10）。
