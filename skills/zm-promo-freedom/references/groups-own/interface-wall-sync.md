## 动作谱
1. 浅色底 → 整面斜铺的界面墙从很虚、很淡中浮出来，同时从右下往左上滑（0.05–0.45s 浮现）
2. 第一行逐词出现在最终位置（灰虚 → 黑实），第二行斜体品牌蓝跟上
3. 墙一路减速慢漂（主段 0.25–1.4s，之后长尾一直在减速、不停死）；墙的上沿淡进底色
4. 停住读字：字层极慢推近，墙按输出秒继续往左上漂
5. 出口：0.3s 内整个画面变虚 + 过曝，越到最后越猛，最后一帧纯白
6. 声音：墙浮现长 whoosh、逐词 tick、出口 riser + 白闪
7. 开始是一片浅色 → 很多块界面一起浮上来证明"哪儿都能用"、两句好处说出来 → 白到底，交给品牌落版

## 意图
用"一整面墙"代替逐个介绍平台：观众不用看清每块界面，只要感到"很多端、都是同一个产品"；白闪干净地交给收尾。

## 动效核心
- 墙是一个整体：一起浮现、一起滑、一起减速；20 块界面互相不单独动（独有）
- 墙的上沿用遮罩淡进底色，不压在字下面（独有）
- 出口的虚和白都是 ease-in（越到最后越猛），最后一帧纯白（独有）

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 墙机位（命门） | rotateX 50° + rotateZ −18°、透视 4000、原点 (960, 600) | 从原片仪表盘和手机的四条边反算：横边往右上抬约 12°、竖边往右下斜约 63°；别凭感觉改 |
| 墙构图（命门） | 20 块界面的位置照原片 51.0s 那帧反算（中排：看板面板、手机任务详情、团队仪表盘、手机项目列表；下排：设置页、手机、蓝色横幅） | 换内容只换每块里面的字，位置大小不动 |
| 滑动距离 | 右下 (300, 190)px → 0，长尾 4.3s | 距离太短就没有"滑进来" |
| 浮现 | 虚 10px → 0、透明 0 → 1，0.05–0.55s | |
| 遮罩 | 画高 30% 以上全透明、56% 以下全实 | 上移会压字 |
| 出口（命门） | 0.28s，虚 0 → 28px + 亮度 1.6，白 ease-in | 匀速发白会泄气 |

## 已知坑
- 墙的运动来自原片逐帧单应（wall-g.ts）：原片是往上滑 ~320px + 1.26→1 倍推远，不是往左上斜滑；墙先摆在原片 51.0s 机位再整体乘屏幕单应
- 2026-11-12 用户看对照："角度不一样呀"。第一版是 rotateX 34° + rotateZ −22°，行太陡、界面几乎没被压扁；改成从原片反算的机位（横边斜率 = tanZ·cosX，竖边斜率 = cosX / −tanZ）；用户再说"跟他一样就好"，又把整面墙的构图也照原片 51.0s 那帧做：量每块界面的角点、按机位反算回墙平面坐标；中间那块大仪表盘换成和原片一样的团队成员表、左边手机换成任务详情页；原片画面比 16:9 窄，左右超出部分按同样的缝补齐。见 run 目录 静帧对照_原片51.0s_左原片右我们.jpg
- 原片的墙是真截图（更密、更"真"），我们是代码画的简化界面，单块细节少；靠数量和倾角撑住"很多端"的感觉
- 原片 48.05 前是上一镜（两部手机）在淡出，我们单独开场时从干净底开始，所以开头 0.1s 活动值比原片低
- 慢漂段逐帧位移在 0 / 1px 之间交替（亚像素移动），--hq 渲染下看不出跳
- 出口的白闪算全画面冲击，同一条片子里别再超过 2 处
