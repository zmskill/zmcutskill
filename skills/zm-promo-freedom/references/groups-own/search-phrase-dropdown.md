## 动作谱
1. 一个历史图标转一下，后面逐词冒出"在找什么"
2. 这句话退掉，换成一个灰色的下拉标题
3. 箭头一路折成 ⌃，标题和箭头往两边拉开
4. 整条往上，下面露出找到的几条记录
5. 开始是"正在找" → 找的对象 → 找到的结果

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| wordT | 每 0.1s 一个词 | 整行一直居中，新词青 → 黑 |
| Chevron k | ⌄ → › → ┐ → ⌃（0.33s） | 命门：一路折过去，和拉开同时 |
| spread | 标题 524 → 196、箭头 → 1686 | 0.26s，先慢后快再慢 |
