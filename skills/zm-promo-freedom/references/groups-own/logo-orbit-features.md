## 动作谱
1. 浅色底 → 图标从小弹出（0.4 → 1，斜 −14°），带光晕，之后一直轻晃
2. 第一行逐词灰虚变实；第二行斜体品牌蓝逐字落下
3. 一圈淡轨道出现 → 6 颗白色小圆从右上开始顺时针每 0.1s 原地弹出一颗
4. 整圈顺时针慢转（约 4°/s），小圆的字一直正着；镜头极慢推近
5. 结尾整画面变虚 + 放大一点 + 淡掉，ease-in（越到最后越快）
6. 声音：图标 pop、逐字 tick、6 颗依次 pop 串、出口 whoosh

## 意图
把前面一镜一镜演示过的功能收拢成一张"全家福"：一个图标在中间，所有功能绕着它转——"都在一个地方"。

## 动效核心
- 小圆原地弹出、顺时针依次，间隔 0.1s（独有）
- 整圈转但字始终正着（独有）
- 出口 ease-in 变虚，不是匀速淡

## 参数表
| 参数 | 典型值 | 调节手感 |

## 已知坑
- 原片圆心在画高 65%；16:9 上下更窄，整组上移到 62%、半径缩到 256px，写满停满时最下面那颗的字离画面下沿约 24px
- 出口活动峰比原片低（我们 0.6 / 1.8 / 1.7，原片 0.8 / 2.5 / 3.3）：原片最后一帧带下一镜的进场，我们单独渲染只有自己淡掉；接进片子时会自然补上
- 停留段靠轨道转 + 图标晃 + 推近保持不冻（原长版 3 格 ≤0.1 冻住，原片 0；拉满版 1 格）
- 图标和 logo-check-build-cta 同一个"勾 + 点"，接在一起观众会觉得是同一个产品；换产品时两组一起换
