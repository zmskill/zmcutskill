## 动作谱
1. 产品名退掉，半句话往左让
2. 右边像老虎机一样一项项往上翻（图标 + 能做的事），越翻越快
3. 停在最后一项，前半句退、最后一项的字从尾巴删掉
4. 只剩图标，滑到正中、变实心、猛地放大铺满

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| ITEM_T | 0.4 → 0.2 → 0.1 → 0.06s | 命门：越翻越快 |
| 暗字颜色 | rgb(54,54,54) | 只是提示还有很多，不能抢 |
| 图标放大 | 170 → 650（0.25s） | 先变实心再放大 |
