## 动作谱
1. 浅色底 + 右下光标 → 白胶囊"新建项目"从小长出 → 大字逐字从下浮上来，第二行在第一行没打完时就开始
2. 光标快速飞到胶囊（快段有拖影）→ 按下 0.93× → 水波圈 → 项目卡从胶囊处撑开（前几帧虚，上沿基本不动），长尾巴补完 → 停住看卡
3. 项目卡缩 0.73× 往上移，三列看板错开 0.1s 从下面浮上来；进度从 0% 开始一路涨
4. 拖卡：拿起（放大 1.05、斜 4°、投影变重）→ 拿着停一下 → 快速横移（横糊）→ 悬停 → 落进新位置 → 角度回正 → 放下，计数同一帧变 → 原列剩下的卡往上补位；两次
5. 第二次落进"已完成"后长出绿勾；光标滑出画，看板停住
6. 镜头全程极慢推近；停留时多推一点
7. 声音：胶囊 pop、逐字 tick、点击、卡撑开 whoosh、看板上浮 whoosh、两次拿起 tick + 放下 thud、完成 ding
8. 开始是一颗"新建项目"按钮 → 建出一个项目、看板展开、事情被一件件推进 → 停在进度涨上去的完整看板上

## 意图
用"建 → 看 → 推"三步把"项目管理"讲成观众看得懂的动作：按一下就有了项目，项目下面是三列看板，拖一下事情就往前走一格、进度就涨。

## 动效核心
- 项目卡是同一个容器：胶囊 → 大卡 → 缩小的卡（独有）
- 被拖的卡始终在最上层；光标钉在卡上一起走；计数和放下同一帧变（独有）
- 原列剩下的卡晚放下 0.05s 往上补位（独有）
- 进度条和数字一起涨，跨越两次拖动，不是每次拖完才跳

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 大字逐字（命门） | 第一行 0.2s 起、共 0.6s；第二行 0.5s 起、共 0.5s（按字数平分） | 字少时每个字更慢，总时长不变 |
| 按下 | 0.93× → 0.96 → 1.0，共 0.12s | 再深就像按坏了 |
| 卡撑开（命门） | 0.96–1.38s，0.1s 到 92%，长尾补完 | 匀速撑开会很"PPT" |
| 卡缩小 | 0.73×，1.95–2.55s ease-out | 缩太小标题看不清 |
| 看板错开 | 0.1s / 列，每列上浮 46px、0.35s | 同时出现会显得一块板糊上来 |
| 拿起 | 放大 1.05、斜 −4°、投影加重 | 斜太多像甩出去 |
| 横移（命门） | 0.1s 内完成大段横移，带横糊 | 慢了就是"搬"不是"拖" |
| 进度 | 2.6–4.9s 涨到 progressTo，S 形 | |

## 已知坑
- 原片画面是 1400×1200，看板在原片里占画宽 77%；按和 023-B、023-C 同一套换算到 16:9 后占 62%，三组放在一起大小一致
- 被拖的卡横移时用整体模糊模拟横糊（原片是方向糊），速度快的 3–4 帧看得出是"整体虚"
- 停留点 1.6s 只有一张卡 + 字：靠全程推近 + 停留时多推 1%/s 保持不冻（活动值 0.1–0.2，原片同段 0.1）
- 写满字停满时，第 3 列最后一张卡离画面下沿约 20px；推近中心放在看板上方（y=700）就是为了这个，别改到画面中心
- 胶囊文字和 023-B 面板顶栏的"新建项目"按钮同名，接在一起时观众会觉得是同一个产品
