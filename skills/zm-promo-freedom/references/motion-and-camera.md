# 运镜、转场、丝滑与卡点

> 本篇管全片的运动语法：画面怎么在空间里走、镜头之间怎么接、速度曲线怎么做到丝滑、动作怎么卡在拍子上。

---

## 一、转场：先看关系，只有三种主力做法

每个接缝先回答两个画面是什么关系，再选接法（写进设计 spec 的 `## 镜头怎么接`）：

| 两个画面的关系 | 接法 | 怎么做 |
|---|---|---|
| 同一件事的延续（输入 → 结果、整体 → 细节） | **飞过去** | 下一个画面和当前画面在同一个 3D `World` 空间里，镜头不停直接飞过去；下一画面在镜头到达前就已在场并已在播放 |
| 换话题、要节奏感 | **卡拍硬切** | 两个**都在动**的画面卡着重拍干脆切，且用 `relay()` 做**速度接力**；零件从动起来那一帧开始取，不加模糊、不淡入淡出 |
| 同一个东西换角度或换比例 | **同物接续** | 同一个视觉锚点在前后两镜同一位置、同一大小，切点那一帧严丝合缝（例：满屏平面 UI → 拉远发现它是 3D 空间里的屏幕） |
| 全片最大的一次叙事转折（如问题 → 答案） | **糊着换**（全片 **≤1 次**） | 失焦退场、甩糊、急推带模糊、光扫、光晕胀满、淡入淡出都算这一类（按观感算，不按名字算） |

- **一条片子里"飞过去"和"卡拍硬切"都要有。**
- **先画镜头路线，再选零件**：设计 spec 写 `## 镜头路线`（将全片分为 2–4 段连续空间，标明每段内各画面的空间坐标 `x, y, z, ry` 与飞行顺序，段与段之间用速度接力硬切）和 `## 每段的展示手法`（画廊穿梭、屏墙环绕、字墙、帧隧道、像素放大、计数连打、取色、翻卡、宫格翻倍、左右对比、页内滚动、逐行扫过等，**同一种手法不重复出现**）。
- `## 镜头怎么接` 每行格式：`上一镜 → 下一镜｜关系：…｜锚点：…（换话题写"无，硬切"）｜接法：飞过去 / 卡拍硬切 / 同物接续 / 糊着换｜落在第几拍`。

## 二、丝滑物理模型：速度是鼓包，没有弹、没有停、没有冻

**丝滑和卡点绝不矛盾：卡在拍子上的是"速度最快的那一刻"和"切的那一帧"，不是"撞停定住的那一帧"。**

观感问题与底层运动学对应表（排查时直接对号入座）：

| 观感毛病 | 底层原因 | 根治做法 |
|---|---|---|
| 顿、一顿一顿 | 速度曲线有尖角；突现（pop） | 每个位移/缩放都带加速与减速鼓包（`ramp`），禁止 1–3 帧弹出定住 |
| 卡、卡住了 | 冻帧（freeze / hold）；中途慢放 | 零件按原速一口气播完，绝不在中途冻帧或变速 |
| 一格一格、重影 | 频闪（judder）；中等速度无模糊，或模糊叠层太稀 | 严格遵守两档速度；开启 `World` 真运动模糊 |
| 像 PPT、翻页 | 静止切静止；靠淡入淡出或糊一下换图 | 用 3D 空间飞过去 + 速度接力硬切 |
| 机械、审美疲劳 | 从头到尾逐拍硬切或逐拍弹卡 | 连着来（连打）只集中在 1 个高潮段，其余跟乐句走 |

### 七条硬规定

1. **所有位移与缩放都是速度鼓包，曲线不能有尖角**：加速 ≥6 帧，减速至少是加速的 2 倍（默认 6 帧起 / 18 帧落，起得快、落得软）。不许 1–3 帧弹出定住、不许带速度急刹、切点两边不用对称 ease-in-out。使用 `ramp()`、`camMoves()` 或带轻微过冲回弹的 `beatLand.ts` `land()`。
2. **镜头永不死停**：两次移动之间保持极慢推进（`camMoves` 的 `drift`，默认每帧前进 3 像素，每次移动到位后重新起算不累计跑偏），避免量片判静止。
3. **零件一口气按原速播完：不冻、不停、不慢放**：`PartPlay` 只用来裁取零件片段（`from`、`to`），禁用 `holds` 和 `fitPart`。对拍只靠三件事：
   - **挪起点**：让零件最核心的落点正好过拍——`起点帧 = onF(拍号) − (落点帧 − 零件起始帧)`（一个零件只对一个主落点）；
   - **镜头飞行**：把镜头每次移动最快的一帧放在拍上（`camMoves`）；
   - **切点**：重拍上速度接力硬切。
   - 需要多看一会儿时，让零件自然播完停稳后靠镜头慢推延续阅读时间，或直接飞走/切走。
4. **切镜头切在速度最高处（Cut on Peak Velocity，`relay()`）**：
   - 上一镜在拍前加速冲出，切在最快那一帧；下一镜第一帧带着**同轴、同向、同速**冲进来再平滑减速（如左出则左进、推近则继续推近，绝不反向掉头）。
   - 两边各移画面宽度的 ~12% 即可，入场时间不短于出场时间；不加模糊、不淡入淡出。
   - **防穿帮**：平移挪开露出的底色必须与画面底色一致（或将底色层铺得比画框宽）；底色反差极大的两镜改用缩放推进接力。
5. **连着来（连打）的节制**：
   - 单次镜头完整鼓包需 ≥20 帧，因此镜头鼓包最密每两拍一次；想每拍一下用速度接力硬切，或一帧事件（数字跳、换词、点亮）。
   - 连打集中在全片 1–2 个段落（连续 4–8 下、间隔相等，安静歌 ≥3 下），不要全片逐拍机械切。
6. **两档速度防频闪**：
   - 读字/看细节档：每帧位移 ≤6px（1080p），无需模糊；
   - 飞行/甩镜档：每帧几十到上百像素，配合真运动模糊半秒内飞完。
   - 避开每帧十几二十像素且无模糊的匀速中速移动（白字深底最易频闪）。飞镜过程中不指望观众读字。
7. **画面比声音早 1 帧（影视剪辑惯例）**：
   - 人脑对视觉信号处理略慢于听觉，画面切点、镜头最快帧、进场鼓包顶点统一用 `onF(拍号)`（比实测响点早 1 帧），音效用 `hitF(拍号)`。切点晚于拍点哪怕 1 帧都会显拖。

## 三、3D 连续空间运镜代码件（`assets/lib/helpers/world.tsx`）

纯 CSS 3D 实现，零额外依赖。**全片大部分时间都应运行在 `World` 空间里**（2–4 段连续空间，每段摆放 2–4 块 Stage，段间用 `relay()` 硬切）：

```tsx
import {World, Stage, camMoves, relay, ramp, punch} from './lib/helpers/world';
import {hitF, onF} from './hits'; // zm_hits.py 生成：画面用 onF（早 1 帧），音效用 hitF

// 1. 镜头 = 一串卡在拍上的鼓包移动，间隙按 drift 持续微推
const cam = camMoves({x: 0, y: 0, z: 1200}, [ // z=1200 时一块 Stage 刚好满屏
  {hit: onF(8),  to: {x: 2700, z: 1300, ry: -22}},                   // 默认拍前 8 帧加速、拍后 16 帧减速
  {hit: onF(12), to: {x: 2700, y: 1900, ry: 0}, lead: 10, tail: 22}, // 落得更柔和
]);

<World cam={cam}>
  <Stage x={0}    y={0}             to={hitF(10)}>
    <PartPlay from={...} to={...}><ShotA /></PartPlay>
  </Stage>
  <Stage x={2700} y={0}    ry={-22} from={hitF(8) - 14} to={hitF(14)} radius={24}>
    <PartPlay from={...} to={...}><ShotB /></PartPlay>
  </Stage>
  <Stage x={2700} y={1900}          from={hitF(12) - 16} radius={24}>
    <PartPlay from={...} to={...}><ShotC /></PartPlay>
  </Stage>
</World>

// 2. 卡拍硬切 + 速度接力（同轴、同向、同速）
const CUT = onF(16);
const r = relay(f, CUT);
{f < CUT
  ? <AbsoluteFill style={{transform: `translateX(${-r.out}px)`}}>...</AbsoluteFill>
  : <AbsoluteFill style={{transform: `translateX(${r.in}px)`}}>...</AbsoluteFill>}

// 3. 元素卡拍进场鼓包（默认 6 帧加速 / 18 帧减速）
const k = ramp(f, onF(20));
<div style={{transform: `translateY(${(1 - k) * 260}px) scale(${0.86 + 0.14 * k})`, opacity: Math.min(1, k * 3)}} />
```

- **纵深布局**：相邻 Stage 前后错开（`z` 差几百像素）、偏转角度（`ry` 15°–35°），镜头沿弧线（`x`/`z`/`ry` 同变）穿行，路过可见相邻屏幕侧面。
- **开启真运动模糊**：`World` 在帧位移 >6px 时自动多子帧叠合真实运动模糊（最多 12 层）。成片绝不允许写 `blur={0}`，也不得用 CSS `blur()` 假装；仅半尺寸小样阶段可用 `blur={4}` 加速渲染。
- **屏内皆活**：Stage 内必须是动态播放的零件、滚动页面或跳动数据，不能贴死图。
- **皮肤融景**：Stage 底色与 World 背景同色时无缝融入空间；作为独立悬浮屏时给圆角并留呼吸边距。

## 四、卡点与冲击规范

1. **拍点一律实测**：通过 `zm_hits.py` 从剪好的音频波形实测起音，生成 `hits.ts`。
2. **拍子上放什么**：镜头最快一帧（`camMoves`）、速度接力切点（`relay`）、鼓包顶点（`ramp`）或弹性落定（`land`）、一帧瞬变（数字跳、换词、亮起）。不放缓慢淡入完成或 2 帧硬弹定住。
3. **重拍四要素同步**：镜头最快刻/切点、转场、重音效、字幕换句齐发。
4. **冲击干净通透**：瞬间高亮用 `punch(f, frame)`（提亮曝光+对比度）或微震/色散，严禁盖半透明白色遮罩导致画面发灰。
5. **安静歌同样卡点**：拉长鼓包（加速 10–14 帧、减速 28–40 帧），每小节一次，落在旋律换句或和弦切换处，至少连着 3 下；若 `zm_hits.py` 提示鼓点不清，请用户听一遍确认拍点。

## 五、每次渲染后的逐格视觉自查

每次小样或成片渲染后，导出 0.1 秒/帧缩略图拼图逐格检查，关键切点与卡点前后 10 帧看全尺寸帧：

```bash
ffmpeg -i out/draft.mp4 -vf "fps=10,scale=192:108,tile=20x15" -q:v 4 reviews/缩略图_%02d.jpg
```

重点排查：黑帧、发灰闪屏、画面死停/冻帧、字幕被遮挡、文字溢框挤字、接缝跳帧、贴图拉伸变形、Stage 边缘穿帮。量片脚本 `tools/zm_film_check.py` 会自动核验卡点分量（第 8 节）、糊着换次数（第 9 节）与顿挫检测（第 10 节）。
