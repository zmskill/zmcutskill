# 产品实测、页面采集与工程搭建

> 展示真实产品页面时，**一律以实机高清截图为基础**，不手画假界面；所有数据、结果和数字必须来自真实使用并做好隐私脱敏。

---

## 一、两条素材采集入口

产物标准统一为：**2x 全页截图 + 关键元素抠图 + `layout.json` 坐标尺寸表**，避免在动画代码里盲猜坐标。

### 入口 A：有产品前端源码（本地启动）
1. 本地启动产品 dev server，先冻结/准备好干净的虚拟演示数据（绝不把真实客户数据、密钥或个人隐私录进画面）。
2. 复制 `assets/scripts/capture-template.mjs` 进片子工程，配置目标路由、视口（推荐 `1440×900` 或 `1920×1080`，`deviceScaleFactor: 2`）与要抠图的元素选择器。
3. 截图前确保等待 `document.fonts.ready` 及页面动效稳定（通常额外等 600ms，实时加载页等 1.5–2s），导出高清 PNG 与元素坐标 `layout.json`。

### 入口 B：无源码 / 线上需要登录的 AI 产品（最常见）
1. 复制 `assets/scripts/capture-live.mjs` 进片子工程，修改 `BASE`、路由与选择器，在片子目录安装 `puppeteer`。
2. 运行脚本弹出独立资料目录（`.capture-profile/`，**绝不提交或分享**）的浏览器窗口。
3. **由用户本人在窗口里亲自登录**，并把页面操作到目标状态（例如先真实跑完一次核心功能，停在结果页）。**AI 绝不代输密码、绝不绕过验证码或访问控制。**
4. 回到终端按回车，脚本按配置采集（停在当前页不跳转的路由设 `path: null`）。
5. 个人信息（用户名、头像、手机号、历史记录）通过 `REDACT` 规则在截图前自动替换或模糊脱敏；设计规范（配色、字号、圆角、阴影）直接从页面 `getComputedStyle` 提取。
6. 若受网络/环境限制无法跑脚本：请用户协助截取全页长图与局部图发来，再量出元素相对坐标写入 `layout.json`。

## 二、产品实测与数据安全清单（有无源码都必做）

- **确认账号与额度**：先确认账号可用、无地区拦截、免费/调用额度充足（防止额度耗尽被误判为产品故障）。
- **出好结果立刻存原图**：AI 生成结果具有随机性，看到优秀产出立即保存原始高分辨率图/导出文件。
- **每个必展功能至少跑两次**：记录稳定度；不稳定的能力不放主角位，最多一带而过。
- **录屏只作动作参考**：录屏用于观察加载态、等待时长和微交互，画面呈现优先用高清静帧/抠图 + 3D 运镜，不直接拿模糊录屏糊满全片。
- **规避原生瑕疵**：记下产品自带水印、生成错字或图文不符处，通过构图避开或在《没做清单》中如实注明。
- **全面脱敏**：演示文字统一使用中性虚构数据（如虚构店名、`you@example.com`），画面里绝不出现真实个人账号、手机号、密钥或未授权的他人隐私。

## 三、Remotion 工程搭建与渲染规范

### 1. 建工程（共享依赖，不重复装包）
开工体检（`tools/doctor.py`）和安装（`tools/setup.py`）完成后，用一行命令给新片子建 Remotion 工程：

```bash
python3 $SKILL/tools/new_video.py <片子目录>
```

- 自动从 `$SKILL/remotion/` 复制配置、基础入口与 `public/library/`（10 款 OFL 字体 + 占位图）、`public/textures/`，并将 `node_modules` 软链到工作区已装好的依赖；
- 若片子目录位于挂载受限环境，自动在工作区搭 `video/`，输出仍写回 `<片子目录>/out/`。

### 2. 编码与渲染铁律
- **确定性渲染**：所有动画严格由 `useCurrentFrame()` 驱动，严禁 `Math.random()`、`Date.now()` 或 CSS `transition`/`animation`；随机数一律用 `assets/lib/helpers/rand.ts`。
- **纹理与图片加载**：所有图片用 Remotion `<Img src={staticFile(...)} />`（不用原生 `<img>` 或 SVG `<image>`），确保渲染等待图片完全加载；3D 倾斜画面使用 2x 高清贴图缩小渲染防发糊。
- **双版本导出参数**：根组件通过 `inputProps` 接收 `bgm?: boolean`（默认 `true`），同一套代码可无改动输出带 BGM 版（`out/promo_raw.mp4`）与纯音效无 BGM 版（`out/promo-nobgm_raw.mp4`），供量片工具分别检测与后续混音使用。
- **先小样、局部修、全尺寸只渲一次**：
  - 半尺寸小样：`npx remotion render src/index.ts <合成名> ../out/draft.mp4 --scale=0.5 --crf=30`
  - 局部重渲验证：`npx remotion render src/index.ts <合成名> ../out/seg.mp4 --scale=0.5 --frames=起-止`
  - 正式成片：全尺寸 1920×1080 / 30fps 渲染后，经 `ffmpeg loudnorm=I=-14:TP=-1.5:LRA=11` 输出最终 `out/promo.mp4` 和 `out/promo-nobgm.mp4`。
