# 小零件（parts）

一个零件 = 一个动作，1–6 秒。它们是从长镜头里按帧切出来的：**动画还是原镜头的，一行没改**，只是可以单独取用。

- 总表：`INDEX.md`（按用途分：痛点、钩子、输入、点击确认、结果登场、功能演示、证据、列举、字卡、转场、过渡动作、品牌落版）
- 每个零件：卡 `references/parts-own/<名字>.md`，代码入口和样片在 `demos-own/parts/<名字>/`
- 给人看的样片页：`demos-own/parts/0_看样片.html`

## 怎么用

1. 按故事的每一拍去"用途"里找，看样片图确认，再读零件卡。
2. 代码入口只是"播原镜头的第几帧到第几帧"。要换文字、截图、颜色，改的是原镜头的代码：先读原镜头卡里的"怎么换内容"和"已知坑"。
3. 只借动作、节奏和调好的参数；界面和文案是演示内容，用到产品上换成产品的真实画面。缓动、时长配比、停顿不改。
4. 一条片子里同一种动作只当一次主角。

## 镜头之间怎么接（这些零件里用到的几种接法）

| 接法 | 怎么做 | 哪个零件里能看到 |
|---|---|---|
| 失焦爬坡硬切 | 上一镜最后 3–4 帧失焦爬升 → 硬切 → 新画面第一帧就是虚的、而且已经在动，清晰比几何晚到 2 帧 | word-card-rise、result-page-tilt-scroll、logo-letters-tagline |
| 急推硬切 | 最后 1–3 帧猛推近（带模糊）→ 硬切到干净的大画面 | wall-pullback-pushin → big-card-liquid-invite |
| 猛推出画 | 大字停住后 2–3 帧猛推出画，直接接下一镜 | big-lines-slam-exit |
| 光晕胀满 | 画面里的一个亮点胀大到满屏变白，退光时下一个画面从光里显出来 | glow-flood-panel-reveal、tags-ring-implode |
| 甩糊换词 | 大字横向甩糊，最空的那一帧换成下一个词 | whip-word-drag-sort |
| 一帧全黑 | 主体冲出画面的那一帧全黑，下一镜从同一方向接进来 | jelly-orb-around-title → orb-to-button-card |
| 虚化换场 | 上一张卡失焦放大变淡，下一张从斜上方虚着进来落定 | blur-swap-stream-write |

硬切都藏在画面动得最快的那一帧里。
