## 意图
硬切进来一个满屏的大标志，一下"砸"到观众眼里，再缩成正常大小、长出名字和标语，安静地停住。

## 动效核心
- 0s 硬切：深藏青底、底部一团蓝光，标志高 400px
- 0–0.13s 猛缩到 110px（4 帧），0.13–0.6s 慢慢再缩到 92px
- 0.57s 起名字逐字浮出（每字晚 0.06s，先灰、虚 6px、字距 0.5em）
- 0.6–1.05s 字距收拢到 0.04em，标志往左让，整组居中；0.85–1.1s 字由灰变白
- 1.2–1.35s 整组上移 26px；1.25–1.65s 标语淡入
- 之后落版：极慢推近 1.2%/秒、底光呼吸、零星小光点往上飘

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 第一下猛缩（命门） | 400 → 110px，0.13s | 慢了就不"砸" |
| 名字字号 | 100px | |
| 字距收拢 | 0.5em → 0.04em，0.45s | |
| 标语 | 26px，字距 0.12em | |

## 声音
0s 硬切一声低沉的 hit；0.57s 名字浮出一串轻 tick；1.25s 标语出来一声很轻的 shimmer。

## 已知坑
- 原片落版段底上有颗粒在动（活动 0.2–0.3）；我们加了小光点往上飘 + 底光呼吸 + 颗粒，但暗场里变化小，仍有 11 格 ≤0.1（原片 1 格）
- 中文名字只有 2 个字，整组比原片 "Pulse" 略窄
