## 意图
用"一行接一行停不下来"的节奏让观众感觉事情很多；高亮那一行固定在中线，眼睛不用找。

## 动效核心
- 硬切进来；字高约 150px、行距 168px；每行左沿在弧上：中线 944 → ±1 行 980 → ±2 行 1049 → ±3 行 1136（逐帧量）
- 每 0.28s（0.05s 起，共 8 次）整圈上转一行，0.1s 走完、长尾巴；每行沿弧走（往上的同时左右移）
- 高亮交接：旧的一行变灰、新的一行变黑、略大一点；蓝球（直径 52px、有高光和外发光）换行时变淡一下
- 两次之间整列极慢往上漂（不冻）

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 步长（命门） | 0.28s 一行 | 慢了像在念清单，快了看不清 |
| 走一行 | 0.1s ease-out | |
| 弧（命门） | 左沿偏移 0 / 36 / 105 / 192 / 290px | 竖直一列就成了普通列表（用户："不是竖着往下的"） |
| 字号 / 行距 | 140 / 168px，字重 500 | |
| 灰度 | 隔一行 #cecfd6，越远越淡 | |

## 声音
每次换行一下很轻的 tick（共 8 下，0.28s 一拍），可以卡在音乐的 16 分音符上。

## 已知坑
- 第一版做成竖直一列 + 平的小圆点，用户："他不是竖着往下的，质感完全不一样，细节差太多了"。根因：只在缩略图上看了"字在往上走"，没量每行左沿；全尺寸一量是弧
- 中文句子比英文短，原片"被右沿裁掉"的感觉要靠 7–9 字的长句才出得来
- 两次之间的慢漂是在步长里扣回来的，第一帧会往回挪约 6px，被换行动作盖住看不出
