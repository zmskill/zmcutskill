## 意图
宣传片开头要先把"用户真的在骂什么"摆出来。这个镜头让观众看到：评论多到铺满一面墙 → AI 从里面挑出最痛的几条 → 每条都有证据（提到多少次、差评多少）→ 收成一张清楚的清单。观众先被"量"压住，再被"挑得准"说服。

## 动效核心
- 发牌（0–76f）：评论卡从右下一张张发到斜墙上，按离右下角的距离排顺序、越来越快；左上计数从 0 跑到 2,317
- 点选（76–124f）：三个彩色光标（AI·频次 / AI·情绪 / AI·影响）分别点中一张卡，描边亮起、吐槽里的关键词被荧光笔从左往右划出
- 展开（124–196f）：其余卡退成背景虚影（模糊 8px、淡到 25%），三张卡飞到前面，下面展开证据卡，数字往上滚
- 收清单，分三拍（196–252f）：① 斜墙摆正、左边先出表头"最痛的 3 条" ② 证据收起、三张卡缩成名牌阶梯排到表头右边 ③ 名牌一个接一个落进行里，那一行先出骨架再填内容
- 标题（256–300f）：逐词出"读完。挑出。说中。"，最后一词用强调色，停住

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 斜机位 | rotateX 10° / rotateY 8° / rotateZ 4°，透视 2600 | 角度再大卡片字会难读；小于一半就不像"斜墙"了 |
| 卡片 | 470×150，5 列 × 5 行，隔列错半格 | 卡要大（推近后约占画宽 1/3），太小就成了纹理 |
| 推近 | 1.08 → 1.22（0–90f） | 推太多会把被点的卡推出画 |
| 选中延迟 | 三张卡在 96 / 104 / 114f 被点 | 间隔 6–10f 才看得出"三个人同时在挑" |
| 收清单节奏 | 名牌落行每张晚 7f | 小于 4f 看着像一起飞，失去"一个个落定"的感觉 |
| 配色 | LOOKS.paper（暖纸 + 墨 + 朱红），三个光标各一种颜色 | 换配色时三个光标颜色要互相拉开 |

## 怎么换内容
- `QUOTES`：25 条吐槽，换成目标产品用户的真实评论（越像原话越好，别润色）
- `PICKS`：被挑中的 3 条在哪个位置、关键词、光标名字和颜色、提到次数、差评占比、来源
- 计数"2,317 条"、清单标题、最后的三词标题按片子改

## 声音
- 发牌段：轻的纸牌 / 卡片落桌声，越来越密（sfx：ui-soft 类）
- 三次点选：各一个短促的点击，钉在 96 / 104 / 114f
- 名牌落行：三下轻"嗒"，钉在 226 / 233 / 240f
- 标题第一词：一个低频 hit（全片 ≤3 个整帧冲击，这里可以占一个）

## 已知坑
- 被点的卡必须在画面中间区域（推近 + 斜放后四角会出画），换内容时别把 PICKS 放到第 0 行或最两边的列
- 计数标签要在展开前淡掉，否则会挡住左上那张证据卡
- 背景卡模糊用的是整层 blur，卡太多时渲染会慢（25 张以内没问题）
- 用户对前几版的意见（已改进本版）："人家是斜着的，而且质感也好很多""框框（不要一个大框框住两张）""过渡不自然（收清单要分拍）"
