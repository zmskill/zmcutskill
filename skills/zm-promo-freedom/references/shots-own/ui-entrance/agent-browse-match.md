## 意图
把"AI 替你上网找东西"拍成一条连续的动作：从打字开始，到网页、到一张张帖子、到具体条件被对上，观众一路跟着同一个东西走，不迷路。

## 动效核心
- S1 远景慢推，侧栏逐行长出，标题逐词浅灰→变深，光标从左下进场
- S2 硬切输入框特写：光标转身、块状打字、横冲向发送键停 0.25s 按下，输入框从光标下面掉走
- S3 硬切远景：消息已发、等待光标转，右上弹出深灰小面板
- S4 2 帧猛推近；面板 深灰→中灰→白底青辉光；面板 2 帧撑大、镜头往左带
- S5 骨架 → 三张帖子卡带青色罩依次弹出 → 各自左右错开（越出面板）
- S6 硬切粉蓝渐变：同样三张卡变漂浮卡，标题被卡片"揭开"，三个光标；标题 3 帧左滑，最后只剩主角卡 + 一个光标
- S7 硬切详情页：拖选"很安静"浅蓝→深蓝选框；一下滚到下一家，左边同一帧换成"有插座"

## 怎么换内容
- `TYPED`（打的那句话）、`RECENTS`（侧栏任务）、`POSTS`（三张帖子卡）、`SHOPS`（详情页）、左边大字两组
- 青色 `CYAN` / `GLOW` 是"AI 正在看"的信号色，换品牌色时整族一起换

## 已知坑
- 硬切前后主角位置要接上；滚动和换词必须同一帧
- 原片背景是实拍叶影，这里用渐变光斑代替；详情卡横幅是简单插画
- 成片用 `--hq`，否则斜放 / 慢移的字会抽动
