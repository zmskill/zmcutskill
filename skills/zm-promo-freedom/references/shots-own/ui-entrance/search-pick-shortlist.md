## 意图
"从一大群人里挑出对的人、再整理成名单"——同一批卡片一路变形（铺开 → 选中 → 展开 → 收成小条 → 变成表格行），不靠硬切讲完整件事。

## 动效核心（2026-11-16 逐帧重量后更正）
- 上排整排往左、下排整排往右"嗖"地滑进（5.27–5.37 最快，5.4 急停后慢漂到 6.6 才停）；卡片层这段几乎不缩放，只有搜索框自己缩窄（左边不动、右边往回收）
- 中间一排 5.53 从右边一帧冲进来，把搜索框挤到左边淡掉
- 5.88–5.97 是"整体逆时针转 4.75° + 推近 12%"（不是后拉），上下两排从两侧滑进；6.0–7.9 镜头按 ECC 逐帧测
- 详情阶段 3 张卡是带透视倾斜的平面，慢慢摆正：逐帧 SIFT + 单应矩阵测四角，用 matrix3d 贴卡（QUADS 数据）；光标按卡面坐标贴
- 选中三态：悬停浅蓝 → 按下深蓝内容变淡 → 松开浅蓝 + 角点选框；陈默选了又退选
- 没选中的退成背景虚影（外圈、底排先退），选中的三张摆正散开，字段每帧一行往下长，"很合适"错开 0.2s 弹出
- 收拢：字段从下往上收 → 小条竖叠漂一下 → 一条条落进表格变浅蓝骨架（斜边擦出）→ 扫光填字 → 绿勾
- 名单先下移让位，三词标题逐词浮现；后拉最快一帧硬切；金句逐词；新搜索框冲上来轻微过冲；冲近发送键按下出玻璃高光；泛蓝转场

## 怎么换内容
- 人物卡数据（姓名、头像 id、职位、公司、城市、年限、学历）、搜索句、详情字段、名单表头、三词标题、金句、第二句
- 头像从 `remotion/public/library/faces/` 选，每张不同、和名字一一对应；平台图标换成画面里对应的真实产品官方图标

## 已知坑
- 原片背景是实拍植物白墙，这里是虚的渐变光影 + 布纹；新搜索框冲上来时白框配白墙不如原片醒目
- 网格倾斜只做了 2D 旋转（原片行斜 -4.9°、列斜 4.6°，有一点透视），取平均 4.75°
- 详情字段 21–22px、表格字按 0.7 镜头约 34px
- 原片的错落其实是"规则网格 + 整体倾斜 + 左右景深"；用户要的前后层 / 大小差异是在这之上加的（后层 0.93–0.965 倍、更虚更淡）
