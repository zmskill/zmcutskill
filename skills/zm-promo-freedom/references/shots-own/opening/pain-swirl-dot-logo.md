## 意图
先用"每天 X 太多"的三连重打把观众拉进一种熟悉的烦躁，四周的小卡片把烦躁具体化；
然后一个漩涡把杂物全吸进中心，"到此为止。"从中心冒出来——杂乱被收走、答案从同一个位置出现；
答案句自己"溢出"成蓝点吞满屏，在纯蓝里换场，天空中心的小白圈接住这个点，Logo 从里面长出来、名字再从 Logo 里拖出来。
"点"贯穿始终：蓝点 → 白圈 → Logo → 名字。

## 动效核心
- 空的柔光浅底先静 0.27s
- 第一句逐词：灰 + 虚 6px + 低 18px → 3 帧变清楚到位 → 再慢慢变墨（最后一个词 0.35s，句尾一直"湿"着）；整句预先按字宽居中，词只显影
- 8 张小卡按顺时针方位（左上 → 右上 → 右下 → 左下 → 上 → 左 → 右 → 下）从画外滑入：强 ease-out、多转 7° 再落回、方向性运动模糊；落定后各走各的小椭圆（≈0.5%/秒）
- 换句 = 整行重打：旧句整行变灰 → 上飘 11px + 虚到 5px + 淡出（0.2s）；新句从"每天"开始逐词从下面虚着升上来，新旧叠 8 帧（"每天"双影）
- 漩涡收走：卡片绕 (50%,47%) 顺时针公转一点、被拉向中心、自转到接近竖直、缩到 0.35×、变虚、后 40% 淡掉，带切向拖影；标题原地缩小变灰变虚
- 碎卡还没走完，"到此 / 为止。"（品牌蓝、斜 10°）逐词浮出，颜色从浅蓝紫加深到 #2D43EE
- 全静 0.32s（原片真停）
- 蓝点从句子几何中心长出：半径每帧约 ×1.3（5→11→19→33→55→86→118→158→207→268→345→450→640→满屏），不缓出
- 纯蓝 2 帧（165–166）里硬切到深蓝天空；天空第一帧中心就有细白圈
- 白圈 → 软光晕环 → 第 1 圈；Logo 方块从小点边转边长（单向自转 120°、略过冲 3%）；三圈白线每 0.2s 出生一圈，强 ease-out 外扩，最后在边缘挤成三道再淡掉
- 星星闪（黄绿 + 白）→ Logo 往左甩（ease-in-out 0.25s，横向拖影，缩到 0.63×）→ 名字从 Logo 右侧逐字淡入（每字 2 帧，无位移，第一个字被 Logo 盖住一半）
- 标语逐词浮现，后半句黄绿斜体 → 静看（只有云层慢漂）→ 横向拖影 + 刷白 0.17s 叠到浅色底

| 3 蓝点 → Logo | `LogoBeat` / `LOGO_BEAT` | 152–276 | 蓝点（152–166）→ 硬切天空（167）→ Logo 长出（170–186）→ 圈外推 + 星星 → 左甩 + 名字（202–213）→ 标语（218–238）→ 静看 → 刷白（267–272） | 从 152 进（需要画面中心有一句品牌蓝的字，蓝点从它中心长出）；只要 Logo 登场可从 167 进 | 240–266：Logo + 名字 + 标语的天空海报；272 后是浅色底 |

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 标题字号 TITLE_SIZE | 104px | ≥96；三句字数要一样（都是 7 个字），整行重打才不跳宽 |
| 逐词：进场 / 变墨 | 0.1s / 末词 0.3–0.36s | 末词变墨再快就失去"湿"的余味 |
| 换句叠化 | 旧句 0.2s 退、新首词在旧句变灰后 2 帧出 | 先出新句再灰旧句会糊成一团 |
| 卡片漂浮 | 振幅 4–8px、周期 3.3–4.4s | 超过 1%/秒就不是"读字时间"了 |
| 漩涡 | 0.5s、公转 ≈20–30°、自转 +80–94°、缩到 0.35× | ease-in-out，中段最快；太短像闪没，太长像慢动作 |
| 蓝点倍率 | 每帧 ×1.3 | 用 ease-out 就软了；满屏纯色至少 2 帧才藏得住硬切 |
| Logo 终态 | 220px 方块，左甩后 0.63×；名字 120px、标语 46px | Logo + 名字整体居中（GROUP_L 自动算） |
| 名字逐字 | 每字 2 帧、0.07s 淡入 | 中文 2–5 字时别再快，会一闪而过 |

## 声音
- 每个词入场：极轻的 tick（可只给每句首词）；换句时一声短促的 "whoosh-up"
- 卡片进场：8 个错开的轻 swish
- 漩涡：一段升调吸气声（116–131），卷没时截断
- 到此为止：静 0.3s（留白），蓝点开始时低频蓄力 → 165 满屏一记"嗡"，167 硬切处放亮的 shimmer
- Logo 长出：上扬的玻璃 chime；名字逐字可配极轻的 tick；刷白：反向 whoosh

## 已知坑
- 远程 VM（Linux arm64）里 渲染环境的 `node_modules` 是 Mac 装的，Remotion 跑不了；在 VM 里另装也会在加载 rspack 时 Bus error。这次是在云端容器装 remotion 4.0.484 + 系统 Chrome（`--browser-executable`）渲染，参数和 render_shot.py 一样（--scale=2 --crf=12 → lanczos 缩回 1920，crf 16）
- render_shot.py 收尾删不掉 `remotion/src/shotlab-root.tsx`（VM 不让删文件），会留着一份；下次渲染会覆盖，不影响
- 原片的玻璃竖条天空、3D 厚玻璃 Logo 没硬画：天空 = 竖向渐变 + 模糊云团 + 静止的极淡竖条纹（云在后面漂，有一点折射视差）；Logo = 白色圆角方块 + 屏幕空间 7 层叠出右下厚度 + Mark
- 原片是 7:6 竖画幅，16:9 里卡片横向往外推了 15%，最外两张收回到 ≤ 92%
- 白字名字压在浅色云上会发灰：云层压低到 50% 以下、加淡紫调，名字和标语加了很淡的深蓝 text-shadow
