## 意图
用"同一颗光球一路变形"把一整条讲解串起来：观众的视线一直跟着球走，不用硬切也不迷路，最后球变成品牌的句点。

## 动效核心（17 段，详见代码分段文件）
- S1–S5（scenes-a）：句中嵌开关 + 句尾弹出光球 → 换词 + 暗色边光球公转 → 光晕胀满屏 → 面板透视摆动、助手球依次亮起
- S6–S10（scenes-b）：资料库卡 + 放入圆吞文件卡（**文件卡在圆前面**）→ 圆被擀成进度条 → 长成文件列表关两个开关 → 果冻球绕标题挤开词缝 → 淡紫球升起变按钮 + 冲击光环
- S11–S17（scenes-c）：串珠成环 + 光标悬停选中 → 双标签画环吸入光团爆亮 → 残弧拉直成虚线夹住胶囊 → 头像球长出 + 3D 对话面板 → 光球绕字标越跑越小落成句点、扫光从落点往左
- 光球：多层径向渐变 + 柔高光 + 边光 + 外发光，按速度方向挤压拉伸，深色核拖在运动反方向；永远压在文字上面

## 已知坑
- 边框必须是有方向的边缘光（orb-kit RimStroke，亮段角度按原片 rim_profile 实测逐段设），不能用 inset 描边一圈 + 外发光一圈（用户 2026-11-17 指出 6 处）
- 面板 / 卡片 / 对话框的透视都来自原片逐帧量的四角（quads-s4.ts、quads-s16.ts），别改回 rotateX/Y
- 文件卡必须盖在放入圆前面（用户指出过做反了）
- 19.7–20.1、28–29、31.5–32 秒漂得很慢，活动曲线接近冻住（原片这几段也很静）
- 果冻球表面的鼓包 / 凹陷没做，只有椭圆挤压拉伸
