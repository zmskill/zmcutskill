## 意图
一个方块变成一整片方块阵，"一个 → 很多"；圈形一波波往里收，像系统在一起同步运转。纯图形，可以放在任何两段之间当节奏点。

## 动效核心
- 0–0.4s 大线框立方体在转；0.4–0.55s 面填深蓝；0.5–0.62s 变亮蓝、缩小
- 0.6s 起镜头从很近一路拉远（每格 400 → 240 → 185 → 168px，先快后慢）：透视机位（转 49°、俯 35°、画面顺时针转 2.5°），中间 2×2 白、外面隔一圈一圈蓝
- 中间 4 个白方块围着蓝色立方体整个长大；外圈在镜头拉远时一圈圈弹出来（0.92 / 1.05 / 1.15s），四周的同样图案 1.15s 后才出现
- 方块：面带渐变（左上亮）、半透明（隐约看到背后的棱）、所有看得见的棱是细白线；地板线走在空着那圈的正中，交点有小白点
- 1.5s、2.4s 换圈形：从外往里每圈晚 0.025s 落下、换色、再升起
- 2.9–3.2s 拉远到每格 85px、同时转正成俯视，四周铺开的图案淡掉，只留中间一块

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 机位（命门） | 透视，焦距 7000px；转 49°、俯 35°、画面顺时针 2.5° | 用正交投影会"平"；角度差几度用户一眼看得出 |
| 方块占格 | 0.67；圈形是"隔一圈一圈" | 相邻两圈都放方块就会挤成一片（第一版错在这） |
| 拉远（命门） | 0.6–0.85s ×420 → ×290，再到 ×165 | 慢了就没有"原来在一片地板上"的感觉 |
| 换圈形（命门） | 从外往里每圈晚 0.025s，落 0.09s、升 0.13s | 整块同时变就成了闪 |
| 收尾 | 2.9–3.2s ×85 + 转正 | |

## 声音
0.6s 拉远一声低频 whoosh；1.5s、2.4s 换圈形各一串从外往里的细碎 tick（0.2s）；2.9s 收尾 whoosh 接下一镜的闪光。

## 已知坑
- 地板中间是 16×16 一块，四周铺开同样的图案（原片中段能看到旁边的图案），最后拉远时只留中间一块
- 一帧最多画约 2000 个方块面，--hq 渲染 96 帧约 35 秒
- 第一版用户看对照："角度细节要跟人家一样"。根因：在 320px 缩略图上目测，用了正交投影、相邻两圈都放方块、颜色偏淡、没有半透明和白棱。返工时改成在全尺寸原帧上量轴线角度、每格像素、取色，按原片 8.1s / 8.9s 两帧反算机位
- 开头的线框立方体角度仍和原片略有差别；最后转正那一下我们比原片更正（原片还带一点斜）
